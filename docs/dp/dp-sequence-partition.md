!!! abstract "要点"
    - **何ができるか**：列をいくつかの区間に区切る方法の数や最小コストを、最後の区間の左端 $j$ で分けて求める。$j$ の範囲が単調に動くなら尺取りと累積和で、区間の番号に依存するなら番号を状態に足して速くする。
    - **いつ使うか**：
        - 列をいくつかの連続部分に分ける方法の数
        - 各区間のコストの和の最小
        - 各区間が条件を満たすように区切れるか
        - $\mathrm{dp}[i] = \sum$（または $\min$）$_{j < i,\ [j, i) \text{ が条件を満たす}}\ \mathrm{dp}[j]$
    - **計算量**：素朴には状態 $O(N)$ × 遷移 $O(N)$ で $O(N^2)$（区間の判定が $O(1)$ のとき）。遷移元の範囲が単調に動くなら尺取りと累積和で $O(N)$、区間の番号を状態に足し、余りごとの和の表で遷移をまとめると $O(N^2)$
    - **前提**：[累積和・いもす法による DP の高速化](../dp/dp-prefix-sum.md)

区間分割 DP は、列を連続する区間に区切る問題を、「先頭 $i$ 個をどう区切るか」の表で解く DP である。区切り方は長さ $N$ の列で $2^{N-1}$ 通りあり、全部は試せない。最後の区間だけを決めれば残りは同じ形の小さい問題になる、という一点を使って $O(N^2)$ に落とし、遷移の形に応じてさらに $O(N)$ まで速くする。

## 最後の区間で分ける（空の区切りを 1 通りと数える） {#last-block}

ここでは列を 0-indexed で $a_0, \dots, a_{N-1}$ と書き、区間は[半開区間](../guide/glossary.md#half-open-interval) $[j, i)$ で表す。列を区切るとは、要素の間の境界 $1, \dots, N-1$ のうち好きなものに仕切りを入れることである。

[状態](../guide/glossary.md#state)は次のように決める。

- **状態**：$\mathrm{dp}[i]$ ＝ 先頭 $i$ 個 $a_0, \dots, a_{i-1}$ を、どの区間も条件を満たすように区切る方法の数
- **遷移**：区切り方を、最後の区間 $[j, i)$ の左端 $j$（$0 \le j < i$）で場合分けする。最後の区間が条件を満たすなら、残りの $[0, j)$ の区切り方は $\mathrm{dp}[j]$ 通りある

$$
\mathrm{dp}[i] = \sum_{\substack{0 \le j < i \\ [j, i) \text{ が条件を満たす}}} \mathrm{dp}[j]
$$

- **初期値**：$\mathrm{dp}[0] = 1$。空の列を区間 0 個に区切る方法が 1 通りある。これがないと、列全体を 1 つの区間にする区切り方（$j = 0$）が数えられない
- **計算順序と答え**：$\mathrm{dp}[i]$ は $i$ より小さい添字だけを使うので、$i$ の昇順に埋める。答えは $\mathrm{dp}[N]$ である

次の図は、$a = (2, 1, 1, 1, 1, 2, 2, 1)$ を「どの区間の和も 4 以下」になるように区切る例である。上段は区切り方の 1 つで、下段は $\mathrm{dp}[6]$ がどの $\mathrm{dp}[j]$ から足し込まれるかを示す。

![上段は列 2, 1, 1, 1, 1, 2, 2, 1 の境界 2・3・6 に仕切りを入れ、区間 [0, 2)・[2, 3)・[3, 6)・[6, 8) に分けた図。下段は dp[0] から dp[8] の表で、最後の区間 [j, 6) の和が 4 以下になる j = 3, 4, 5 の dp[j] が dp[6] に足し込まれる。j = 2 は和が 5 になるので遷移元にならない。点線の dp[7]・dp[8] は、dp[6] を求める時点ではまだ求めていない](../img/dp-sequence-partition/last-block.svg)

この分け方で重複も漏れもないのは、区切り方と「最後の区間 $[j, i)$ と、先頭 $j$ 個の区切り方」の組が一対一に対応するからである。最後の区間は区切り方ごとにちょうど 1 つ決まり、それを取り除いた残りは先頭 $j$ 個の区切り方になる。逆に、先頭 $j$ 個の区切り方の後ろに $[j, i)$ をつなげれば元の区切り方に戻る。区間の条件がその区間の中身だけで決まるので、前の区切り方が後ろの区間に影響しない。だから $\mathrm{dp}[j]$ という 1 つの数で足りる。

同じ骨組みで、数え上げ以外の問いにも答えられる（[DP の基本](../dp/dp-basics.md#three-kinds)の 3 つの型）。

| 問い | 遷移 | 初期値 | 届かない状態 |
| --- | --- | --- | --- |
| 区切り方の数 | $\sum \mathrm{dp}[j]$ | $\mathrm{dp}[0] = 1$ | 0 |
| コストの和の最小 | $\min (\mathrm{dp}[j] + \mathrm{cost}(j, i))$ | $\mathrm{dp}[0] = 0$ | $+\infty$ |
| 区切れるか | $\mathrm{dp}[j]$ の OR | $\mathrm{dp}[0] = \text{true}$ | false |

計算量は、状態が $N + 1$ 個で各状態の遷移元が最大 $N$ 個なので、区間の条件の判定が $O(1)$ なら $O(N^2)$ である。区間の和は[累積和](../basics/prefix-sum.md) $S_0 = 0$、$S_{i+1} = S_i + a_i$ で $S_i - S_j$ と $O(1)$ で求まる。判定に $O(N)$ かかる条件なら全体は $O(N^3)$ になるので、区間ごとの判定を先に表にしておくか、次の節以降の方法で遷移をまとめる。

??? question "確認問題：$\mathrm{dp}[0]$ を 0 にすると"
    「どの区間の和も $K$ 以下」に区切る方法の数で、$\mathrm{dp}[0] = 0$ から始めると答えはどうなるか。

    ??? success "答え"
        すべての $\mathrm{dp}[i]$ が 0 になり、答えも 0 になる。どの区切り方も、最初の区間 $[0, j)$ を最後の区間と見た $\mathrm{dp}[j]$ への遷移で $\mathrm{dp}[0]$ を使う。$\mathrm{dp}[0]$ は「まだ何も区切っていない」状態の数で、空の区切り方が 1 通りあるので 1 にする。

## 区間 DP との違い {#vs-interval-dp}

区間分割 DP と[区間 DP](../dp/interval-dp.md) は、どちらも列の区間を扱うが、表の持ち方が違う。

- **区間分割 DP**：$\mathrm{dp}[i]$ は先頭 $i$ 個、すなわち左端を 0 に固定した区間 $[0, i)$ の答えである。最後の区間を 1 つ決めて、左に残った $[0, j)$ に帰着する。状態は $O(N)$ 個
- **区間 DP**：$\mathrm{dp}[l][r]$ は任意の区間 $[l, r)$ の答えである。区間の内側の分け目 $m$ で $[l, m)$ と $[m, r)$ に割る。状態は $O(N^2)$ 個で、遷移を合わせると $O(N^3)$ になりやすい

区間分割 DP で足りるのは、区間ごとのコストや条件がその区間の中身だけで決まり、区切った後の区間どうしが影響し合わない場合である。「各区間の和を $K$ 以下に」「各区間のコスト $\mathrm{cost}(j, i)$ の和を最小に」は、この形をしている。

区間 DP が要るのは、操作の結果で隣の区間が変わる場合である。たとえば「隣り合う 2 つを合体させ、そのたびに合計の大きさだけコストがかかる」では、どの順で合体したかで途中の塊の大きさが変わる。「区間を取り除くと両隣がくっつく」も同じで、取り除いた後に新しく隣り合ったものの扱いが残る。こうした問題は最後の区間を決めても左の部分が独立にならないので、内側を割る区間 DP にする。

??? question "確認問題：どちらの DP か"
    次の 2 つは、区間分割 DP と区間 DP のどちらで解くのが自然か。(1) 列をいくつかの区間に区切り、各区間の最大値と最小値の差の和を最小にする。(2) 列から隣り合う 2 つを選んで 1 つにまとめる操作を繰り返し、最後に 1 つにする。各操作のコストは 2 つの値の和で、コストの合計を最小にする。

    ??? success "答え"
        (1) は区間分割 DP である。各区間のコストはその区間の中身だけで決まるので、$\mathrm{dp}[i] = \min_j (\mathrm{dp}[j] + \max - \min)$ と書ける。(2) は区間 DP である。最後の操作でまとめる 2 つの塊が $[l, m)$ と $[m, r)$ で、それぞれの塊を作るコストが部分問題になる。

## 遷移元の範囲が単調に動く：尺取りと累積和 {#two-pointers}

素朴な $O(N^2)$ が間に合わない $N = 2 \times 10^5$ 程度の問題では、遷移元 $j$ の集合の形を見て遷移をまとめる。いちばんよく出るのは、区間の条件が「区間を縮めても保たれる」場合である。

$[j, i)$ が条件を満たせば、それに含まれる $[j', i)$（$j \le j'$）も満たすとする。たとえば $a_k \ge 0$ のときの「和が $K$ 以下」や「転倒数が $K$ 以下」「同じ値を 2 つ含まない」がこの型である。このとき $i$ を固定すると、条件を満たす $j$ はひと続きの範囲 $[\mathrm{lo}_i, i)$ になる。さらに $i$ を右に進めても $\mathrm{lo}_i$ は左に戻らない。$[j, i + 1)$ が条件を満たせば、それを縮めた $[j, i)$ も満たすからである。これは[尺取り法](../basics/two-pointers.md#two-types)の「部分区間も満たす型」そのものである。

したがって、$\mathrm{lo}$ を尺取りで進めながら、$\mathrm{dp}$ の累積和 $T_0 = 0$、$T_{i+1} = T_i + \mathrm{dp}[i]$ を一緒に作れば、遷移は 1 回の引き算になる。

$$
\mathrm{dp}[i] = \sum_{j = \mathrm{lo}_i}^{i - 1} \mathrm{dp}[j] = T_i - T_{\mathrm{lo}_i}
$$

$\mathrm{lo}$ は全体で $N$ 回しか進まないので、全体は $O(N)$ になる（区間の値の出し入れが $O(1)$ のとき）。次のコードは、0 以上の整数の列を、どの区間の和も $K$ 以下になるように区切る方法の数を求める。$\mathrm{lo} = i$ になったら、$a_{i-1}$ だけで $K$ を超えているので 0 通りである。

```cpp
--8<-- "dp-sequence-partition/sum-at-most-k.cpp:core"
```

同じ考え方の変形がいくつかある。

- **転倒数のように出し入れに手間がかかる量**：右端に $a_{i-1}$ を入れると、窓の中の $a_{i-1}$ より大きい要素の数だけ[転倒数](../ds/inversion-number.md)が増える。左端の $a_{\mathrm{lo}}$ を出すと、窓の中の $a_{\mathrm{lo}}$ より小さい要素の数だけ減る。どちらも値で数えるので、[座標圧縮](../basics/coordinate-compression.md)した値の [BIT](../ds/fenwick-tree.md) で $O(\log N)$ になり、全体は $O(N \log N)$
- **「区間を広げても保たれる」条件**：$a_k \ge 0$ で「和が $K$ 以上」（$K \ge 1$）なら、条件を満たす $j$ は $[0, \mathrm{hi}_i]$ という接頭辞になり、$\mathrm{hi}_i$ も単調に増える。遷移は $T_{\mathrm{hi}_i + 1}$ を読むだけになる
- **最小コストで遷移元が範囲**：$\min_{\mathrm{lo}_i \le j < i} \mathrm{dp}[j]$ の形なら、引き算ではまとめられない。範囲の両端が単調に動くのでスライド最小値（deque）を使うか、セグメント木で範囲の最小を取る（[セグメント木・スライド最小値による DP の高速化](../dp/dp-segment-tree.md)）
- **除く $j$ が値で決まる**：「どの区間の和もちょうど $K$ にならない」では、条件を満たさない $j$ は $S_j = S_i - K$ となる $j$ だけである。負の値があると範囲にはならないが、全部の和 $T_i$ から「累積和の値が $S_i - K$ である $j$ の $\mathrm{dp}[j]$ の和」を引けばよい。後者は累積和の値をキーにした連想配列に $\mathrm{dp}[j]$ を足し込んでおけば $O(\log N)$ で読める（[尺取り法](../basics/two-pointers.md#negative-values)で負の値を扱うのと同じ道具）
- **遷移元が少数に限られる**：同じ結果を何通りにも数えないよう、遷移元を「直前の同じ値の位置」など 1〜2 個に絞れる場合がある。[例題](#agc031_b)がこの型である

??? question "確認問題：和が K 以上"
    $a_k \ge 1$ の列を、どの区間の和も $K$ 以上（$K \ge 1$）になるように区切る方法の数を $O(N)$ で求めたい。$\mathrm{dp}[i]$ の遷移はどう書けるか。

    ??? success "答え"
        $[j, i)$ の和 $S_i - S_j$ は $j$ を小さくするほど大きくなるので、条件を満たす $j$ は $S_j \le S_i - K$ となる $j$、すなわち $0 \le j \le \mathrm{hi}_i$ の範囲である。$i$ が増えると $S_i$ も増えるので $\mathrm{hi}_i$ は減らない。$\mathrm{hi}$ を尺取りで進め、$\mathrm{dp}[i] = T_{\mathrm{hi}_i + 1}$（$\mathrm{hi}_i$ がなければ 0）とする。

## 区間の番号に依存する条件：番号を状態に足す {#block-index}

この節は[余り・個数を状態に持つ DP](../dp/dp-mod-state.md)を前提にする。区間の条件が「左から何番目の区間か」で変わるなら、$\mathrm{dp}[j]$ だけでは足りない。先頭 $j$ 個を何個の区間に区切ったかで、次の区間に課される条件が変わるからである。そこで区間の個数を状態に足す。

- **状態**：$\mathrm{dp}[i][k]$ ＝ 先頭 $i$ 個を、ちょうど $k$ 個の区間に、どれも条件を満たすように区切る方法の数
- **遷移**：最後の区間 $[j, i)$ が $k$ 番目の区間の条件を満たすなら $\mathrm{dp}[j][k - 1]$ を足す
- **初期値と答え**：$\mathrm{dp}[0][0] = 1$。答えは $\sum_k \mathrm{dp}[N][k]$（区間の個数が決まっている問題なら $\mathrm{dp}[N][L]$）

状態が $O(N^2)$ 個に増えるので、遷移を $O(1)$ にまとめないと $O(N^3)$ になる。典型は「$k$ 番目の区間の和が $k$ で割り切れる」という条件である。区間 $[j, i)$ の和は $S_i - S_j$ なので、条件は次のように言い換えられる。

$$
S_i - S_j \equiv 0 \pmod{k} \iff S_j \equiv S_i \pmod{k}
$$

遷移元は「$S_j$ を $k$ で割った余りが $S_i$ と同じ $j$」になり、範囲ではなく余りで決まる集合になる。そこで余りごとの和の表を持つ。

- $B[k][r]$ ＝ これまでに見た $j$ のうち $S_j \bmod k = r$ のものについての $\mathrm{dp}[j][k - 1]$ の和
- $\mathrm{dp}[i][k] = B[k][S_i \bmod k]$

$i$ を昇順に回し、各 $i$ でまずすべての $k$ について $\mathrm{dp}[i][k]$ を $B$ から読み、その後で $B[k][S_i \bmod k]$ に $\mathrm{dp}[i][k - 1]$ を足す。読む前に足すと、長さ 0 の区間 $[i, i)$ を数えてしまう。$B[k]$ の大きさは $k$ なので、表の大きさは $\sum_k k = O(N^2)$、時間も $O(N^2)$ で、$N = 3000$ 程度まで間に合う。

区間の個数が決まっていて、コストの和を最小にする問題も同じ形の表になる。区間の個数を $L$ として、$\mathrm{dp}[i][k] = \min_j (\mathrm{dp}[j][k - 1] + \mathrm{cost}(j, i))$ は素朴には $O(LN^2)$ かかる。$\mathrm{cost}$ が Monge 性を持つときは、最適な $j$ が $i$ について単調になることを使って速くでき（[Monge 性による DP の高速化](../dp/monge.md)）、さらに区間の個数の次元を外す方法として [Alien DP](../dp/alien-dp.md) がある。どちらも発展の道具なので、ここでは「個数を状態に足すと $L$ 倍になる」と「それを外す道具がある」ことだけを押さえておけばよい。

## 落とし穴 {#pitfalls}

**$\mathrm{dp}[0]$ を入れ忘れる・答えを取り違える**。$\mathrm{dp}[0] = 1$（最小化なら 0、可否なら true）を置かないと、最初の区間からの遷移がすべて消える。答えは $\mathrm{dp}[N]$ だけで、$\sum_i \mathrm{dp}[i]$ ではない。途中の $\mathrm{dp}[i]$ は「先頭 $i$ 個で区切り終えた」数で、残りの要素が区間に入っていない。

**長さ 0 の区間を数える**。遷移元は $j < i$ で、$j = i$ を含めない。累積和で $T_i - T_{\mathrm{lo}}$ と書くと $j = i$ は自然に外れるが、$T_{i+1}$ を使うと $\mathrm{dp}[i]$ 自身が混ざる。余りごとの表を使うときは、「読む → 足す」の順を守る。

**1-indexed の問題文と添字がずれる**。問題文の $A_1, \dots, A_N$ を $a_k = A_{k+1}$ と読み替え、区間は半開区間 $[j, i)$、和は $S_i - S_j$ にそろえる。「$l$ 番目から $r$ 番目まで」を閉区間のまま扱うと、$S_r - S_{l-1}$ と $S_r - S_l$ を取り違えやすい。

**尺取りの条件が単調でない**。$a_k$ に負の値があると「和が $K$ 以下」は縮めても保たれず、$\mathrm{lo}$ を単調に動かせない。単調かどうかを「区間を 1 つ縮めても条件が保たれるか」で必ず確かめ、成り立たなければ値で引く連想配列や、別の高速化を考える。

**累積和の引き算が負になる**。mod を取った累積和の差 $T_i - T_{\mathrm{lo}}$ は負になりうるので、$\mathrm{MOD}$ を足してから余りを取る。

**区間の判定が重い**。判定 1 回に $O(N)$ かかる条件で $O(N^2)$ 個の区間を毎回調べると $O(N^3)$ になる。$N \le 100$ 程度なら許されるが、それより大きければ判定を前計算するか、尺取りで差分だけを更新する。

## 使い分け {#comparison}

- 区切った区間どうしが影響し合わない → 区間分割 DP（$\mathrm{dp}[i]$）。合体や削除で隣が変わる → [区間 DP](../dp/interval-dp.md)（$\mathrm{dp}[l][r]$）
- 区切る条件が「各区間の和が $M$ の倍数」のように余りだけで決まり、区間の番号に依存しない → 区間の個数は要らず、$S_j \bmod M$ ごとの和だけで遷移できる（[余り・個数を状態に持つ DP](../dp/dp-mod-state.md)）
- 区切り方が 1 通りに決まる（後ろから照合すると切り方が一意になる、など）→ DP をせず貪欲で足りることがある（[後ろから・逆順に考える](../thinking/reverse-thinking.md)）
- 遷移元が範囲で、和なら累積和、最小なら[セグメント木・スライド最小値](../dp/dp-segment-tree.md)。どの道具を選ぶかの全体は [DP の高速化の選び方](../dp/dp-speedup-overview.md)

## 例題 {#examples}

### AGC031 B. Reversi {#agc031_b}

<div class="kp-problems" data-role="example" markdown>

- [AGC031 B. Reversi](https://atcoder.jp/contests/agc031/tasks/agc031_b)（diff 1315）：石の列で、同じ色の 2 つの石を選んでその間を同じ色に塗る操作を何回でも行うとき、最終的に作れる色の列の種類数を求める。

</div>

最終的な列は、元のまま残った石と、両端が同じ色の区間を塗りつぶした塊に分かれる。塊どうしが入り組まないのは、色の違う 2 つの操作の区間が交差していると、先に塗った方が後の方の端の石の色を変えてしまい、両方は行えないからである。同じ色の操作どうしが交差するなら、合わせた 1 つの区間を塗るのと同じになる。だから塊は重ならず、これを区間分割として数える。$c_0, \dots, c_{N-1}$ を石の色とし、$\mathrm{dp}[i]$ ＝ 先頭 $i$ 個だけを考えたときに作れる列のうち、石 $i - 1$ が元の色のまま残るものの数 とする。操作の両端の石は色が変わらないので、石 $N - 1$ は必ず元の色であり、答えは $\mathrm{dp}[N]$ である。

石 $i$ を最後の石にした列は、2 つの場合に分かれる。石 $i$ を右端とする塗りつぶしがない場合は $\mathrm{dp}[i]$ 通りである。ある場合は、左端を「石 $i$ より左で同じ色の、最も右の石 $p$」に限ってよい。もっと左の同じ色の石 $p'$ から塗った結果は、$[p', p]$ と $[p, i]$ を順に塗った結果と同じだからである。こうして遷移元が高々 2 つになる。

$$
\mathrm{dp}[i + 1] = \mathrm{dp}[i] + \begin{cases} \mathrm{dp}[p + 1] & (p \text{ があり } p < i - 1) \\ 0 & (\text{それ以外}) \end{cases}
$$

$p = i - 1$（隣が同じ色）を除くのは、塗っても列が変わらず、塗らない場合と同じ列を二重に数えるからである。$\mathrm{dp}[0] = 1$ から始め、色ごとに直前の出現位置を配列で持てば $O(N + M)$ で求まる（$M$ は色の数）。答えは $10^9 + 7$ で割った余りで出す。

??? note "解法の詳細"
    - 前処理：$\mathrm{last}[c]$ ＝ これまでに見た色 $c$ の石の最も右の位置（なければ $-1$）を持つ。
    - $i = 0, 1, \dots, N - 1$ の順に、$p = \mathrm{last}[c_i]$ とし、$\mathrm{dp}[i + 1] = \mathrm{dp}[i]$、さらに $p \ge 0$ かつ $p < i - 1$ なら $\mathrm{dp}[p + 1]$ を足す。その後 $\mathrm{last}[c_i] = i$ とする。
    - 2 つの場合が重ならない理由：塗りつぶしがない場合、石 $i - 1$ は元の色 $c_{i-1}$ のままである。塗りつぶしがある場合、石 $i - 1$ は色 $c_i$ になる。$p < i - 1$ のときは $c_{i-1} \ne c_i$ なので（$c_{i-1} = c_i$ なら $p = i - 1$ になる）、2 つの場合で石 $i - 1$ の色が違う。
    - 塗りつぶしがある場合の列は、石 $p$ から石 $i$ までが色 $c_i$ で、先頭 $p + 1$ 個は石 $p$ が元の色のまま残る列なので、ちょうど $\mathrm{dp}[p + 1]$ 通りある。
    - 小さい列で全通りの操作を試した結果と一致することを確かめておくと安心である。

## 練習問題 {#practice}

<div class="kp-problems" data-role="practice" markdown>

- [ARC065 C. Daydream](https://atcoder.jp/contests/arc065/tasks/arc065_a)（diff 930）：文字列 S を dream・dreamer・erase・eraser の連結に区切れるかを判定する。
- [ABC207 E. Mod i](https://atcoder.jp/contests/abc207/tasks/abc207_e)（diff 1820）：数列をいくつかの区間に区切り、各区間の和が、左から数えたその区間の番号で割り切れるようにする方法の数を求める。
- [典型90 089. Partitions and Inversions（★7）](https://atcoder.jp/contests/typical90/tasks/typical90_ck)（diff —）：数列をいくつかの区間に区切り、各区間の転倒数が K 以下になる区切り方の数を求める。

</div>

??? note "練習の方針"
    - **ARC065 C**：$\mathrm{dp}[i]$ ＝ 先頭 $i$ 文字を 4 つの単語に区切れるか。最後の区間は 4 つの単語のどれかなので、遷移元は単語の長さ 5・6・7 に応じて $i - 5$・$i - 6$・$i - 7$ の 3 か所である（長さ 5 の単語は dream と erase の 2 つ）。区間 $[j, i)$ の文字列がその長さの単語のどれかと一致し $\mathrm{dp}[j]$ が true なら true にする。$O(\lvert S \rvert)$。後ろから照合する貪欲でも解ける
    - **ABC207 E**：区間の番号を状態に足し、$\mathrm{dp}[i][k]$ を「累積和を $k$ で割った余り」ごとの和の表 $B[k][r]$ から読む（[番号を状態に足す](#block-index)）。$N \le 3000$ で $O(N^2)$
    - **典型90 089**：区間を縮めても転倒数は増えないので、条件を満たす左端の範囲 $[\mathrm{lo}_i, i)$ は単調に動く。転倒数の出し入れを BIT で数えながら尺取りし、$\mathrm{dp}$ の累積和で数える。値が大きいので先に座標圧縮する。$O(N \log N)$

## 力試し {#challenge}

<div class="kp-problems" data-role="challenge" markdown>

- [ARC104 C. Fair Elevator](https://atcoder.jp/contests/arc104/tasks/arc104_c)（diff 2009）：一部が欠けたエレベーターの乗り降りの記録を、条件を満たすように補えるかを判定する。

</div>

??? note "力試しの方針"
    - **ARC104 C**：乗った階と降りた階の $2N$ 個の座標を、重なる人どうしでまとめると、各まとまりは長さが偶数の連続した範囲 $[l, l + 2d)$ を占め、前半の $d$ 個が乗る階、位置 $x$ で乗った人は $x + d$ で降りる形になる。$\mathrm{dp}[v]$ ＝ 座標 $[0, v)$ をまとまりに区切れるか として区間分割の可否 DP をする。各区間がまとまりになれるかは記録と矛盾しないかを $O(N)$ で調べ、全体は $O(N^3)$（$N \le 100$）。欠けた記録の扱い（片方だけ分かっている人の位置が、範囲の前半・後半の正しい側にあるか）で誤判定しやすい

## 確認問題 {#quiz}

??? question "確認問題：区切り方の総数"
    長さ $N$ の列を、条件なしで連続する区間に区切る方法は何通りあるか。区間分割 DP の式から確かめよ。

    ??? success "答え"
        $2^{N-1}$ 通りである（$N \ge 1$）。条件がないと $\mathrm{dp}[i] = \sum_{j < i} \mathrm{dp}[j]$ で、$\mathrm{dp}[0] = 1$、$\mathrm{dp}[1] = 1$、$\mathrm{dp}[2] = 2$、$\mathrm{dp}[3] = 4$ と、$i \ge 1$ で $\mathrm{dp}[i] = 2^{i-1}$ になる。境界 $N - 1$ か所のそれぞれに仕切りを入れるかどうかを選ぶ数とも一致する。

??? question "確認問題：区切る個数の上限"
    「どの区間の和も $K$ 以下」に加えて「区間の個数は $L$ 個以下」という条件が付いたら、表はどう変えればよいか。

    ??? success "答え"
        区間の個数を状態に足し、$\mathrm{dp}[i][k]$ ＝ 先頭 $i$ 個を $k$ 個の区間に区切る方法の数 とする。遷移は $\mathrm{dp}[i][k] = \sum_{j = \mathrm{lo}_i}^{i - 1} \mathrm{dp}[j][k - 1]$ で、$k$ ごとに累積和を持てば $O(1)$ になる。答えは $\sum_{k \le L} \mathrm{dp}[N][k]$ で、全体は $O(NL)$ である。
