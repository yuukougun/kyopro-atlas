!!! abstract "要点"
    - **何のページか**：各ページの「勉強したい」で入れたページを、題名・レベル・分野・入れた日の一覧で見られる。読み終えたページや要らなくなったページは、一覧から外せる。
    - **使い方**：あとで読みたいページを見つけたら、そのページの上の「勉強したい」を押す。次に何を読むか迷ったら、並べ方をレベルの順にして易しいものから読む。
    - **前提**：なし

勉強したいリストは、あとで読みたいページを集めておく一覧である。記録はこのブラウザの中だけにあり、「解いた」「理解した」と同じ方法で書き出し・読み込みができる。

## 入れ方と外し方 {#how}

- **入れる**：各ページの上にある「勉強したい」を押す（ページの下にも同じものがある）。しおりの印が塗られ、もう一度押すと外れる。
- **外す**：上のリストの「外す」を押す。外した直後なら、「元に戻す」で入れた日ごと戻せる。
- **並べ方**：入れた日の新しい順・古い順、レベルの順、分野の順から選べる。レベルの順では基礎 → 水 → 青 → 黄 → 発展の順に並べ、レベルのない案内のページは最後に置く。

勉強したいリストは「理解した」とは別の記録である。理解したページもリストに残り、ページのレベルの「理解した」が付いていれば、行に「理解した」の印が出る。読み終えて要らなくなったら外す。

前提のつながりから次に読むページを探すときは[知識マップ](knowledge-map.md)を、色ごとの読む順を見るときは[色別ロードマップ](roadmap.md#reading-order)を使う。

## 記録の保存と退避 {#storage}

記録は、このブラウザの localStorage に、ページの id と入れた日時として保存する。サーバには送らず、端末どうしでも同期しない。同じブラウザのほかのタブで入れたページは、開いているリストに直ちに反映する。

別の端末へ移すときや退避するときは、[この教材の使い方の「書き出しと読み込み」](../start/how-to-use.md#backup)の欄で、記録をファイルに保存して読み込む。書き出す記録には、解いた・理解した・勉強したいの 3 つがすべて入る。
