この教材は、多くの人が公開してきた解説記事・問題集・ライブラリの上に成り立っている。例題の解き方を確かめるとき、手法の説明を組み立てるとき、事実を確かめるとき、そのたびに誰かが書き残した記事に助けられた。各ページの参考の節は出典を示すためのもので、謝意を伝える場所ではない。そこで、このページで改めて感謝を示す。

## 特に多く参考にした書き手 {#main-thanks}

参考の節に挙げたページの数が特に多い 4 人の書き手に、とりわけ深く感謝する。並びは[書き手と資料](#writers)の表の順である。

- **drken 氏**：参考に挙げたページの数がいちばん多い。ABC を中心とする多くの問題の解説記事で、基礎と水のページを中心に、例題と練習問題の問いと方針を確かめた。[桁 DP](../dp/digit-dp.md)・[燃やす埋める](../graph/project-selection.md)・[掃き出し法](../math/gaussian-elimination.md)・[期待値と確率の変換](../comb/expectation-tail-sum.md)などでは、考え方を整理した記事が説明を組み立てる手がかりになった。
- **kmjp 氏**：ABC の G・Ex を中心とする後半の問題の解説を、多くのページで参考にした。青・黄・発展のページの練習問題は、kmjp 氏の解説で問いと方針を確かめたものが多い。
- **ikatakos 氏**：コンテストごとの問題メモで、水のページを中心に、多くの練習問題の方針を確かめた。[ラグランジュ補間とべき乗和](../math/lagrange-interpolation.md)と[線形漸化式の高速化](../math/linear-recurrence-fast.md)では、手法をまとめた記事を参考にし、学ぶための資料にも挙げた。
- **E869120 氏**：GitHub に公開されている典型90問の問題文・解説・解答コードで、典型90問から採った多くの例題と練習問題を確かめた（[例題と練習に使った問題集](#problem-sets)）。上達のガイドライン（中級編・上級編）は、[精進の仕方](../guide/practice-method.md)と[コンテストの戦い方](../guide/contest-strategy.md)で、解説を見るまでの時間と解く速さの目安の資料にした。

## 例題と練習に使った問題集 {#problem-sets}

本文の例題と練習問題の大半は ABC・ARC・AGC の過去問である。一部は、AtCoder の上にコンテストの形で置かれた問題集から採った。主なものは、競プロ典型 90 問（考察の典型）、EDPC（DP の基本形）とその先の TDPC、鉄則本の演習問題集、アルゴリズムと数学 演習問題集、ACL Practice（ACL の機能）である。それぞれの中身は[問題集と練習用コンテストの案内](../guide/problem-sets.md#collections)で読める。手法ごとの最初の例題として解ける問題がそろっているので、例題を選びやすかった。問題集を作って公開している方々と、ABC・ARC・AGC の問題を作ってきた方々に感謝する。

典型90問・鉄則本の演習問題集・アルゴリズムと数学 演習問題集では、E869120 氏が GitHub に公開している次の資料も参考にした。本そのものは資料にしていない。

- [kyopro_educational_90](https://github.com/E869120/kyopro_educational_90)：典型90問の問題文・解説・解答コード
- [kyopro-tessoku](https://github.com/E869120/kyopro-tessoku)：『競技プログラミングの鉄則』の章立てと、章ごとの解答コード
- [math-algorithm-book](https://github.com/E869120/math-algorithm-book)：『アルゴリズム×数学』の解答コード

## 教材の作成に使ったサービスとライブラリ {#tools}

教材を作り、確かめ、公開するために、次のサービスとライブラリを使わせてもらっている。作り、保守している方々に感謝する。

- **AtCoder Problems**：公開データで問題の実在・題名・difficulty を確かめ、[問題の台帳](https://github.com/yuukougun/kyopro-atlas/blob/main/data/problems.yaml)の元データにした。difficulty の意味も、AtCoder Problems の文書で確かめた。
- **AtCoder Library（ACL）**：本文のコード片が呼び出すライブラリである。使い方は公式の文書（document_ja）で確かめた。
- **Library Checker**：自作のコードを確かめるための問題として、手法のページの「自作の確認」に挙げている（[自作ライブラリの設計と動作確認](../guide/library-design.md#verify-table)）。
- **MkDocs・Material for MkDocs・PyMdown Extensions**：Markdown からサイトを作る。
- **KaTeX**：数式を表示する。
- **Cytoscape.js・cytoscape-dagre**：[知識マップ](../guide/knowledge-map.md)などの、ページの前提関係の地図を描く。
- **Mermaid**：一部のページの図を描く。
- **textlint**：本文の表記を検査する（preset-ja-technical-writing・prh などの規則）。
- **GCC**：コード片をコンパイル・実行して確かめる。
- **GitHub**：リポジトリを置き、GitHub Actions で検査し、GitHub Pages で公開し、Issue で連絡を受ける。
