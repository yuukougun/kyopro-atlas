# kyopro-atlas

AtCoder で黄色（レーティング 2000）を目指す人のための、辞書として引く競技プログラミングの教材である。解けなかった問題から手法を引き、前提をたどって読み、色ごとの順に学べる。想定する読者は、ABC の D までは安定して解け、E は時々解ける人である。

AtCoder 株式会社とは関係のない、個人による非公式の教材である。本文は AI（Claude）で書いている（[出典と AI 利用の方針](start/ai-and-sources.md)・[謝辞](start/acknowledgments.md)）。

## 目的別の入口 {#entrances}

目的に合うカードを選び、その最初の行のページから読む。
