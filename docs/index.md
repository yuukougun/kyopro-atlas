# kyopro-atlas

AtCoder で黄色（レーティング 2000）を目指す人のための、辞書として引く競技プログラミングの教材である。解けなかった問題の言い回しや制約から手法を引き、前提をたどって読み、色ごとの順に学べるようにする。

!!! info "制作中"
    このサイトは制作中である。多くのページは「準備中」で、冒頭の要点だけを載せている。準備中のページの要点は目次から機械的に作ったもので、本文はまだない。

## 入口

- [知識マップ](guide/knowledge-map.md)：ページの前提関係をたどる

- レベル別の一覧：準備中（[すべての一覧](lists/index.md)）
- 用語の索引（準備中）：手法の名前・別名・英語名から引く
