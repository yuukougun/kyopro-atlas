## 手引きへの提案

- render_svg.py の `--width 720`（既定の 2 つ目）で撮ると、高さ 400 前後の SVG の下端が切れて写る（見本の binary-search-answer/staircase.svg でも同じ）。360 px か `--scale 2` では全体が写る。Chrome の headless でウィンドウの高さが描画域より小さくなっているようなので、道具の側で高さに余白を足すとよい
- dp の分野の書き方（§5）に「数え上げの区間 DP は、1 つの対象がただ 1 つの分け方に対応するもの（左端の相手など）で分ける」を足す案。最小化では重複が害にならないが、数え上げでは誤りになる点が、区間 DP と区間分割 DP の両方で繰り返し出る
