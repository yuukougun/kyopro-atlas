## 指摘

### 1｜直すべき｜事実（F1・F10）｜front matter の summary「全体で O(N log N) になる」

- **問題**：summary の計算量が $O(N \log N)$ で、complexity と要点の $O(M \log M)$（$M$ は値の上限）と食い違う。例題 ABC162 E では $N$ が列の長さで、ループは $K$ まで回るので、$N$ と読むと誤りになる。本文の落とし穴「値の上限ではなく個数まで回す」とも反する
- **根拠**：本文 #order「配列の長さや列の長さ $N$ ではなく、値の上限まで回す」、complexity の「値の上限 M に対して…O(M log M)」
- **直し方**：（執筆者が提案済み。メインが反映）summary の末尾を「値の上限を M とすると、F がそろっていれば全体で O(M log M) になる。」にする

### 2｜直すべき｜事実（F5）｜#practice の ABC304 F の行の要約（台帳 abc304_f の summary と alternatives の summary）

- **問題**：要約「N の約数 M を周期に持つという条件を満たすシフト表の数」は、$M$ が $N$ 未満であることが抜けている。$M = N$ を許すとどの表も周期 $N$ を持つので、問いの意味が変わる。また「条件」が何か（予定の文字列で決まる日に勤務が固定される）が分からず、問いだけを読んでも何を数えるか伝わらない
- **根拠**：drken「AtCoder ABC 304 F - Shift Table」の問題の要約（周期 $M$ は $N$ より真に小さい $N$ の約数）。本文の練習の方針も「$N$ 未満の $N$ の約数 $d$」と書いており、要約とだけ食い違う
- **直し方**：（執筆者が提案済み。メインが台帳を直して fix_problems を流す。kmp の例題の行も同じ要約なので一緒に直る）例：「'.' と '#' からなる予定 S について、条件を満たし、N 未満の N の約数 M を周期に持つ長さ N の勤務表の数を mod 998244353 で求める。」。台帳の abc304_f と abc206_e・abc162_e・abc361_f に `checked: 2026-10-21` を入れる提案も添える（上の evidence で問いを確かめた）

### 3｜直すとよい｜コード（C3）・事実（F3）｜#perfect-powers の「下のコードは余裕をみて 62 まで回す」と perfect-powers.cpp 249 行のコメント

- **問題**：本文は「$2^{60} > 10^{18}$ なので指数は 59 までで足りる」、コードのコメントは「2^62 > 10^18 なので、指数は 61 以下で足りる」で、根拠の書き方が食い違う。さらにコメントは「61 以下で足りる」と言いながら `B = 62` でループは $b = 62$ まで回る。また cases の $2^{60}$（1152921504606846976）は、コメントの入力の範囲「n <= 10^18」の外にある
- **根拠**：perfect-powers.cpp 219・249 行、yaml の 5 つ目の case
- **直し方**：コメントを「2^60 > 10^18 なので指数は 59 までで足りる。余裕をみて 62 まで回す」に直す。入力の範囲のコメントを「n <= 2^62 程度まで」とするか、$2^{60}$ の case を $10^{18}$ に替える

### 4｜直すとよい｜分かりやすさ（U3・U6）｜#gcd-sum、コードの後の「合わせて $O(M \log M + M \log N)$ である」と #order の 3 つ目の箇条

- **問題**：この節では $N$ が定義されていない（#partition では $N$ は ABC162 E の列の長さ）。部分集合のコードで $2^{c}$ を作る手間は $O(\log c)$ で、$c$ は数列の長さ以下だが、読者は「$N$ はどれか」で止まる。#order の「$c^N$ や $2^c$ の形なら…$O(\log N)$」も、$2^c$ のときは $N$ ではなく $c$ の log である
- **直し方**：#gcd-sum の冒頭で「数列の長さを $N$ とする」と 1 句足すか、「$O(M \log M + M \log N)$（$N$ は数列の長さ）」と書く。#order は「指数の log の手間」とする

### 5｜直すとよい｜分かりやすさ（U3）｜#perfect-powers の最後の段落「こちらは $O(N^{1/3} \log N)$ かかるが」

- **直し方**：「列挙の方法はソートに $O(N^{1/3} \log N)$ かかるが、約数包除なら $K$ 乗根を 60 回ほど求めるだけで済む」と主語を書く

### 6｜直すとよい｜記法（F7）｜#perfect-powers の見出しと sections の title「完全累乗などの重複を指数ごとに除く」

### 7｜直すとよい｜分かりやすさ（U8）｜#quiz「lcm がちょうど L」の答え

- **問題**：「$F(d)$ … は、lcm が $d$ の約数であるものに排反に分かれる」は、「lcm が $e$（$e$ は $d$ の約数）のものへ、$e$ ごとに排反に分かれる」の意味だが、「lcm が $d$ の約数であるもの」が 1 つの集まりにも読める。また、求めたい答えが $f(L)$ であることが書かれていない
- **直し方**：「lcm は $d$ の約数 $e$ のどれか 1 つなので、$F(d)$ は lcm が $e$ のものへ $e$ ごとに排反に分かれ、$F(d) = \sum_{e \mid d} f(e)$ となる。$L$ の約数を小さい順に見て約数の側から引き、答えは $f(L)$」とする
