## 指摘

### 1. 直すべき｜事実（F2）｜#counting-phases の Ears の段落（96 行目）

- **問題**：「どの段階でも位置ごとのコストは $A_i$ と回数の偶奇だけで決まる」は誤り。「0 回」と「正の偶数回」はどちらも偶数だが、コストが違う（0 回なら $A_i$、正の偶数回なら $A_i = 0$ のとき 2・それ以外は $A_i \bmod 2$）。偶奇だけで決まるなら段階は 3 つ（偶・奇・偶）で足りることになり、5 段階にする理由と食い違う。同じページの練習の方針（209 行目）のコストとも合わない
- **根拠**：drken「みんなのプロコン 2019 D - Ears」（https://drken1215.hatenablog.com/entry/2019/02/10/014800）のコスト（0 回の段階は $A_i$、偶数の段階は $A_i$ が正の偶数で 0・奇数で 1・0 で 2、奇数の段階は奇数で 0・偶数で 1）。上の全列挙でも、このコストの 5 段階の DP が正しいことを確かめた
- **直し方**：「どの段階でも位置ごとのコストは、段階の種類（0 回・正の偶数回・奇数回）と $A_i$ だけで決まる」のように直す

### 2. 直すとよい｜分かりやすさ（U3）・事実（F2）｜導入（46 行目）

- **問題**：「区間を 1 つ選ぶことは、各位置に段階を付けて $0 \to 1 \to 2$ と増えていく列を作ることと 1 対 1 で対応する」は、段階 1 が少なくとも 1 つある（かつ 1 段ずつ進む）条件が抜けている。0 と 2 だけの列（例 0, 0, 2）は区間を決めない。条件は #kadane（56 行目）で初めて出る
- **根拠**：#kadane の 56 行目「1 の並びが空でない」と、空の区間を許すときの 0 → 2 の遷移の話
- **直し方**：「段階 1 の位置が 1 つ以上ある、$0 \to 1 \to 2$ と増えていく列」のように条件を一言足す

### 3. 直すとよい｜分かりやすさ（U4）｜#counting-phases の遷移の一般形（94 行目）

- **問題**：「段階に長さ 0 を許すなら $q \le p$ のすべてから来られ、許さないなら $q \in \{p-1, p\}$ だけ」は、ページ全体を 1 つの規則で決めるように読める。実際は段階ごとに決まる（Kadane でも段階 0・2 は長さ 0 でよいが、段階 1 は長さ 0 を許さない）。また、最初の段階の長さ 0 は初期値（位置 0 で 0 → 1 に進める）で、最後の段階の長さ 0 は答えに $\mathrm{dp}[N][1]$ を含めることで表しており、遷移で飛ばすのは「間の段階」だけである。この区別がないと、#kadane の遷移（$q \in \{p-1, p\}$ なのに前と後は長さ 0 でよい）と結び付けにくい
- **根拠**：#kadane の遷移と「初期値と答え」、落とし穴の「答えに含める段階」
- **直し方**：「段階 $q$ から $p$ へ直接進むことは、間の段階 $q+1, \dots, p-1$ の長さを 0 にすることにあたる。間の段階がどれも長さ 0 でよいときだけ $q \to p$ を許す。最初の段階の長さ 0 は初期値で、最後の段階の長さ 0 は答えに含める段階で表す」のように書き分ける

### 4. 直すとよい｜分かりやすさ（U7）｜練習の方針の Ears（209 行目）

- **問題**：5 段階の分け方・各段階のコストの式（3 通りの場合分けまで）・遷移の範囲がそろっていて、解き方の全部になっている。さらに本文の #counting-phases（96 行目）でも 5 段階と長さ 0・計算量まで述べており、練習として自分で考える部分が残らない。手引きの「方針が答えそのもの」にあたる
- **根拠**：clarity.md U7、style-guide §10（練習の方針は折りたたみに、解き方が見えないように）。内容自体は drken の記事と一致する（指摘 1 の文を除く）
- **直し方**：方針は「経路の左端・始点・終点・右端で数直線を 5 つに分け、各部分で通る回数の性質（0 回・正の偶数回・奇数回）を考える。各部分の長さは 0 でもよい」程度で止め、コストの式は外す。本文 96 行目の例は段階の数を示す役目なので、そのままでよい
