## 指摘

### 1. 直すべき｜事実（F1・F10）｜front matter の complexity と要点の「計算量」（13 行・40 行）

- 問題：「$k \ge \ln(1/\delta)/p$ 回で足りる（$p = 1/4$、$\delta = 10^{-9}$ なら 73 回）」の括弧の 73 は、式 $\ln(1/\delta)/p$ の値ではない。式に入れると $4 \ln 10^9 \approx 82.9$ で 83 回になる。73 は $(3/4)^k \le 10^{-9}$ を正確に解いた値で、確認問題 1 の答えはこの 2 つを正しく分けている。要点だけを読む人は式と例が食い違って見える
- 根拠：4·ln(10^9) = 82.89、⌈ln(10^-9)/ln(3/4)⌉ = 73（Python）
- 直し方：complexity と要点の両方を「…$k \ge \ln(1/\delta)/p$ 回で足りる（$p = 1/4$・$\delta = 10^{-9}$ なら 83 回。$(1 - p)^k \le \delta$ を正確に解けば 73 回）」とする

### 2. 直すべき｜事実（F1・F2）｜color-coding の「サイン：$K \le 10$ 程度」（163 行）と、要点の「いつ使うか」の 2 つ目（front matter の signs）

- 問題：K 色で塗る Color Coding は、成功確率が $K!/K^K$ なので $K = 10$ では 1 回あたり約 1/2756 になり、$\delta = 10^{-9}$ で約 57000 回、$\delta = 10^{-3}$ でも約 19000 回の試行が要る。1 回が $O(2^K (N + M))$ なので、$K = 10$ では $(N + M)$ に $2 \times 10^7$〜$6 \times 10^7$ が掛かり、制限時間に収まらない。本文の「時間に収まるかを確かめる」とも合わない。実用は $K \le 6$〜$7$ 程度（$K = 6$ で約 1333 回 × 64 ≈ $8.5 \times 10^4$ 倍）
- 根拠：K = 4〜10 の ⌈ln δ / ln(1 − K!/K^K)⌉ × 2^K を計算した。K = 6：1333 回・8.5×10^4、K = 7：3376 回・4.3×10^5、K = 8：8613 回・2.2×10^6、K = 10：57098 回・5.9×10^7
- 直し方：本文のサインを「$K \le 6$〜$7$ 程度で…」とし、「$K$ が 1 増えると回数がおよそ $e$ 倍・1 回の手間が 2 倍になる」と 1 文添える。signs（要点の「いつ使うか」）は執筆者が変えられないので、メインへの提案として「$K \le 7$ 程度の少数の要素を選ぶ条件で、要素の種類が多い」への変更を報告に書く

### 3. 直すとよい｜事実（F1）｜color-coding の「$e^K \ln(1/\delta)$ 回ほど繰り返し」（154 行）

- 問題：$e^K$ は $K^K/K!$ の上界で、$K = 6$ では $e^6 \ln 10^9 \approx 8350$ 回と、必要な約 1333 回の 6 倍になる。「ほど」と書くと実際の目安と読まれる。直前の文で $K = 6$ が約 $1/65$ と出しているので、そこから回数を出すほうが分かりやすい
- 直し方：「塗り直しと DP を $(K^K/K!) \ln(1/\delta)$ 回（$e^K \ln(1/\delta)$ 回以下）繰り返す。$K = 6$・$\delta = 10^{-9}$ なら約 1340 回である」

### 4. 直すとよい｜分かりやすさ（U3）・図（G5）｜落とし穴の「Boyer-Moore の候補を数え直さない」（183 行）

- 問題：「図の列から A を 1 個除くと…候補に残る」は、どの A を除いても最後は cnt = 0 になる（例：A B A C A B → (A,1)(—,0)(A,1)(—,0)(A,1)(—,0)）。図の書き方では cnt = 0 の候補は「—」なので、図に合わせて追うと候補は残らない。コード片では変数 `cand` に A が残るので誤りではないが、図と本文の読み方が食い違う
- 直し方：cnt が 0 にならない例に替える。例「過半数がない列でも候補は何かの値になる（1 2 3 では候補は 3、cnt は 1）」。図の列を使うなら「最後は cnt = 0 だが、コードの `cand` には A が残る」と書く

### 5. 直すとよい｜分かりやすさ（U3）｜落とし穴の「同じ 2 つを選ぶ」（184 行）

- 問題：「その回を飛ばして数えると」は「飛ばして（回数に）数えない」とも読め、その場合は条件付きで異なる 2 つの一様な選び方になり、見積もりは崩れない。崩れるのは 114 行のとおり「飛ばした回も 1 回に数える」ときである
- 直し方：「$i = j$ の回を飛ばしたうえで試行 1 回に数えると、成功確率が $1/4$ を下回る（$N = 3$、$m = 2$ なら $2/9$）」
