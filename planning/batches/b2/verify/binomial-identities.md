## 指摘

### 1．直すべき｜事実（F2・F7）｜落とし穴「範囲外の約束に頼れない項がある」（230 行）

- **問題**：「上の数が負になる項（$\binom{-1}{-1}$ など）は約束の外で、式によっては 1 と扱うべきこともある」とあるが、このページ（51 行）と binomial-coefficient#out-of-range の約束は「$k < 0$ や $k > n$ では 0」で、$\binom{-1}{-1}$ は $k = -1 < 0$ なので約束の中に入り、0 になる。コード片の `binom` も `n < 0 || k < 0 || k > n` で 0 を返す。読者は「約束の外なら自分の `binom` は何か別の扱いをする（あるいは assert で止まる）」と受け取りうるが、実際には黙って 0 が返る。問題の本質は「約束を当てはめると 0 になるが、正しい値は 1」である
- **根拠**：本文 51 行と binomial-coefficient.md 94 行の約束の書き方。手引き §5 comb の「範囲外を 0 とする約束だけでは空の組を落とすことがある。… $\binom{-1}{-1}$ になるが、答えは 1 である」。snippets/binomial-identities/rect-sum.cpp・verify.cpp の `binom`
- **直し方**：たとえば「上の数が負になる項（$\binom{-1}{-1}$ など）も約束では 0 になるが、空の組を数える式では 1 であるべきことがある（$x_1 + \dots + x_n = k$ の解の個数 $\binom{k+n-1}{n-1}$ の $n = k = 0$、[ABC290 F](#challenge) の $N = 2$ の $\binom{N-3}{k-1}$）。和の添字を付け替えたら、上の数が負になる項がないか、あれば正しい値かを確かめる」のように、「約束の外」をやめて「約束では 0 になる」と書く

### 2．直すとよい｜分かりやすさ（U5）｜parity-sum の「偶奇の条件の言い換え」（99 行）と例題 ABC262 E の方針（248 行）

- **根拠**：99 行と 248 行を並べて読んだ
- **直し方**：99 行は「グラフの辺の条件の偶奇を、頂点ごとの量（次数）の偶奇に直すと、この形の和になることがある（[ABC262 E](#abc262_e)）」の 1〜2 文にとどめ、理由は例題の方針に任せる（または逆に、節に理由を置き、例題の方針を短くする）

### 3．直すとよい｜分かりやすさ（U3）｜vandermonde の $r$ 因子への一般化（121 行）

- **問題**：「選んだ数のうち $a_1 + 1$ 番目・$a_1 + a_2 + 2$ 番目・… の $r - 1$ 個を区切りにする。すると、$j$ 番目の区切りの間にある数の個数が $b_j$」の「$j$ 番目の区切りの間」が、どの区切りとどの区切りの間かが分からない。区切りの数（$r - 1$ 個）と区間の数（$r$ 個）の対応、区切り自身は $b_j$ に数えないことが書かれていない。主張そのものは全列挙で正しいことを確かめた
- **根拠**：レート 1000 前後の読者として 1 文ずつ読み、区間の数え方で止まった
- **直し方**：「$(j-1)$ 番目と $j$ 番目の区切りの間（先頭から 1 番目の区切りまで、$r - 1$ 番目の区切りから末尾までも含める）にある、区切り以外の数の個数が $b_j$、その中で選んだ数の個数が $a_j$ になる。区切りを除いた数は $m$ 個なので $b_1 + \dots + b_r = m$ になる」のように補う。$r = 2$ がすぐ上の形（区切りが $i$）に戻ることを一言添えるとつながりが見える
