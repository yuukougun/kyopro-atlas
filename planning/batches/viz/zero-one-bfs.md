## config

`{"n": 5, "source": 0, "edges": [[0, 1, 1], [0, 2, 1], [0, 3, 0], [3, 2, 0], [1, 4, 0], [2, 4, 1]], "pos": [[70, 150], [220, 240], [370, 150], [220, 60], [520, 240]]}`

仕様：

- 項目は `n`（1〜8）、`edges`（0〜12 本の `[u, v, w]`。w は 0 か 1）、`directed`（既定 true）、`source`（既定 0）、`labels`（省略可）、`pos`（省略可。省略時は円の上に並べる）。本文の辺は有向なので、`directed` の既定は dijkstra と逆にした
- Error にするもの：重みが 0・1 以外、自己ループ、同じ 2 頂点を結ぶ 2 本目の辺（逆向きも。描くと重なるため）、ほか形の誤り。viz.js が「図を表示できなかった：…」と出す

## 動きとステップ

- 本文の「処理の流れ」と同じ書き方で動かす。先頭の (d, u) を取り出し、d > dist[u] なら古い組として読み飛ばす。そうでなければ出る辺を辺の並びの順に見る。d + w < dist[v] なら更新し、w = 0 なら (d, v) を先頭へ、w = 1 なら (d + 1, v) を末尾へ入れる
- 初期状態と、取り出し 1 回ごとに 1 状態で、本文の表と同じ 7 状態になる。取り出した組・更新・操作の後の deque・読み飛ばし（(1, 2)）・最終の dist = 0, 1, 0, 0, 1 が、すべて表と一致する
- caption の例：「0 → 3（重み 0）で dist[3] を ∞ → 0 にし、(0, 3) を先頭へ入れる。」「dist[2] を 1 → 0 に縮め、(0, 2) を先頭へ入れる。(1, 2) は古い組になる。」「1 → 4（重み 0）では 1 + 0 = 1 で、dist[4] = 1 より小さくならない。」「dist[2] = 0 < 1 なので古い組であり、読み飛ばす。」
- 状態の項目：`phase`（init / pop / stale）・`dist`・`done`・`deque`（先頭 → 末尾）・`newFront` と `newBack`（このステップで先頭・末尾に入れた数）・`popped`・`stale`・`updated`（`front` 付き）・`kept`（縮まなかった辺）・`last`・`caption`
- 描画は色だけに頼らない
    - 辺：重み 0 は実線、重み 1 は破線（静的な図と同じ）。今回縮めた辺は太線
    - 頂点：確定済みは塗り（文字は太字）。取り出した頂点には輪を付け、読み飛ばしなら破線の輪にする。暫定距離は頂点の横に置き、縮んだ頂点は「1→0」の形の太字にする
    - 下の行：「取り出した組」と「deque（先頭 → 末尾）」。今回入れた組は太枠にし、枠の下に「先頭へ」「末尾へ」と文字で書く。古い組は破線の枠と取り消し線
    - 凡例は 2 行
