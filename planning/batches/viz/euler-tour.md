# 動く図 euler-tour（行きがけ順の in・out と、部分木が列の区間になること）

## 作ったもの

- `overrides/assets/js/viz/euler-tour.js`：見本（binary-search・lazy-segment-tree）と lca.js と同じ形。`states(config)` は DOM を使わない純粋な関数、`render(svg, state, config, h)` が描く。`viewBox` は木の深さと n で決まり、ステップによらない（幅は 380 以上。本文の例で 380、n = 10 でも 472）
- `tests/viz/euler-tour.test.mjs`：試験 7 件
- `docs/tree/euler-tour.md`：div（config は執筆者のまま）の前の段落を直した。元の文「…頂点 2・5・6・0 の部分木が列の区間として順に光る」は色だけに頼る言い方なので、「次の動く図では、上に木、下に行きがけ順の列 $b$ と頂点ごとの in・out の表を置く。DFS が頂点へ入るごとに番号を振り、出るときは out を書き込む様子を追ったあと、頂点 2・5・6・0 の部分木と、それに当たる列の区間を括弧で順に示す。」にした。div の後の段落はそのまま

## config

`{"n": 7, "parents": [-1, 6, 0, 2, 5, 0, 2], "select": [2, 5, 6, 0]}`（執筆者の仮のものから変えていない。静的な図 subtree-interval.svg と同じ木）

- `n`：1〜10 の整数（列のマスが n 個並ぶので、幅 360 で読める上限）。頂点は 0-indexed で根は 0
- `parents`：長さ n。`parents[0] = −1`、ほかは 0 以上 n 未満の整数で、親をたどると根に着く（自己ループ・閉路は誤り）。番号の順でなくてよい。葉は 6 個まで（lca と同じ）
- `select`：省略可。DFS の後に部分木と区間を示す頂点の配列（10 個まで、重複可）。省略または空なら DFS だけ
- DFS は本文の処理の流れと同じく、根 0 から子を番号の小さい順に回る。入るとき in[v] ← timer・b[timer] ← v・timer を 1 増やす。出るとき out[v] ← timer
- 誤りは見本と同じく Error を投げ、viz.js が「図を表示できなかった：…」と出す（data-config がない・n の範囲・parents の長さと値・根・自己ループ・閉路・葉の数・select の形と値）

## 描き方とステップ（本文の例で 20 状態）

- 上から、見出し（「頂点 1 に入る：in[1] = 4」「頂点 2 から出る：out[2] = 5」「頂点 2 の部分木 = 区間 [1, 5)」など）、木（子を番号の順に、葉を左から並べる）、列 b（マスに頂点、下に位置 t。DFS の間は見出しに timer）、頂点ごとの in・out の表
- 状態：初め → 入る・出るの各事象（2n 個）→「DFS が終わった」→ select の頂点ごとに部分木
- 本文の例：入る順 0, 2, 3, 6, 1, 5, 4。in = [0, 4, 1, 2, 6, 5, 3]、out = [7, 5, 5, 3, 7, 7, 5]。部分木は 2 → [1, 5)（2・3・6・1）、5 → [5, 7)（5・4）、6 → [3, 5)（6・1）、0 → [0, 7)。前後の文章と一致する
- caption の例：「頂点 6 の子 1 に入る。in[1] = 4 とし、列の位置 4 に 1 を置く。timer は 5 になる。」「頂点 2 の子孫をすべて回り終えた。出るときの次の番号 5 を out[2] とする。」「頂点 2 の部分木（2・3・6・1）は区間 [1, 5)。番号 1〜4 は頂点 2 に入ってから出るまでに振られ、長さ 5 − 1 = 4 は部分木の頂点数に等しい。」
- 色だけに頼らない：いまの頂点・書いたマスは太枠と太字、DFS の道（根からいまの頂点）と部分木の中の辺は太線、まだ入っていない頂点・空のマスは点線や薄い塗り、区間は列の上の括弧と「[1, 5)」の文字。見出しと caption で何が起きたかを文字で書く
