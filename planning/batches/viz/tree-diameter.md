# 動く図 tree-diameter（2 回の最遠点探索で直径を求める）

## 作ったもの

- `overrides/assets/js/viz/tree-diameter.js`：double sweep の動く図。見本（binary-search・lazy-segment-tree）と lca.js と同じ形で、`states(config)` は DOM を使わない純粋な関数、`render(svg, state, config, h)` が描く。`viewBox` は木の描き方と並べ直した描き方の大きい方で決まり、ステップによらない
- `tests/viz/tree-diameter.test.mjs`：試験 7 件
- `docs/tree/tree-diameter.md`：div（config は執筆者のまま）の後の段落に 2 文を足した。「図では下のコードの `max_element` と同じく番号の小さい頂点 0 を選び、直径 5–4–3–2–1–0 を得る。各頂点の右下の数はいまの探索での距離で、最も遠い点の候補は破線の輪で示す。」div の前の段落はそのまま

## config

`{"n": 9, "edges": [[0, 1], [1, 2], [2, 3], [3, 4], [4, 5], [2, 6], [6, 7], [3, 8]], "start": 7}`（執筆者の仮のものから変えていない）

- `n`：1〜12 の整数。頂点は 0-indexed
- `edges`：長さ n − 1。各要素は `[u, v]`（0 以上 n 未満の整数、u ≠ v）。全体で木（閉路なし。辺が n − 1 本なので連結になる）。重みはない
- `start`：1 回目の探索の始点 s（省略すると 0）
- 幅 360 で読めるよう、s を根にした描き方の葉の数と、直径を横一列に並べた描き方の列の数（直径の頂点ごとに、ぶら下がる枝の葉の数か 1）がどちらも 7 以下でなければ Error（列 7 つで viewBox の幅 472）。この検査は states の中で行う（viz.js は viewBox を try の外で呼ぶので、viewBox で投げると誤りの表示にならないため）
- 誤りは見本と同じく Error を投げ、viz.js が「図を表示できなかった：…」と出す（data-config がない・n の範囲・edges の長さと形・自己ループ・閉路・start・幅の制限）
- 最も遠い点が同点のときは、本文のコード（`max_element`）と同じく番号の最も小さい頂点を選ぶ。距離は BFS で層ごとに求める（コードは DFS の順だが、重みなしなので距離は同じ）

## 描き方とステップ（本文の例で 16 状態）

- 状態：① 始点 s → 距離 1, 2, … の層ごと（その層の頂点を太枠にし、右下に距離の数を出す）→ 「最も遠い点 a」（候補に破線の輪、a を塗って名札 a）→ ② a から同じく層ごと → 「最も遠い点 b」（候補 0 と 7 に破線の輪、b を塗る）→ 「a–b のパスが直径」（パスの辺を太線）→ 並べ直した図
- 並べ直した図：直径 a → b を横一列に並べ（太線）、残りの頂点を付け根の真下へ枝としてぶら下げる（破線）。上に「直径の長さ 5」の目盛り。静的な図 spine.svg と同じ描き方。caption で枝の深さが付け根から近い方の端までの長さ以下であること（頂点 3 の枝は深さ 1 ≤ 2、頂点 2 の枝は深さ 2 ≤ 2）を書き、本文の正しさの鍵の不等式につなげた
- 本文の例：s = 7 から距離 5 の頂点 5 が a、a = 5 から距離 5 の頂点 0 と 7 が同点で、番号の小さい 0 を b とする（caption で「7 を選んでも長さ 5 の直径になる」と書く）。直径 5–4–3–2–1–0、長さ 5。前後の文章と一致
- 色だけに頼らない：距離は数字、いまの層は太枠、候補は破線の輪、s・a・b は名札の文字、端点は塗り、直径は太線、並べ直した図の枝は破線

## 未解決の点

- 重みのある木には対応していない（本文の図の例は重みなし）。重みを付けるなら config に weights を足し、層ごとではなく距離の小さい順に確定させる形に変える必要がある
- 並べ直した図は木の描き方より低いので、viewBox を共通にした分、上下に余白が出る（真ん中に置いた）
- 線の色は lca.js と同じく、kp.css に線用の class がないので `style` に Material の CSS 変数を直接書いた
- caption の長さが状態ごとに違うので、幅 360 では操作のボタンの位置が上下する（ほかの図と同じ）
