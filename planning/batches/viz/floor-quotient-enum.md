# 動く図 floor-quotient-enum（商の列挙）

## 作ったもの

- `overrides/assets/js/viz/floor-quotient-enum.js`：⌊N/i⌋ の棒の階段の上で、商が同じ区間 [l, r] を左から 1 つずつ取り、Σ ⌊N/i⌋ に (r − l + 1) × q を足す動く図。見本（binary-search・lazy-segment-tree）と同じ形で、`states(config)` は DOM を使わない純粋な関数、`render(svg, state, config, h)` が描く。`viewBox` は N だけで決まり、ステップによらない
- `tests/viz/floor-quotient-enum.test.mjs`：試験 7 件
- `docs/math/floor-quotient-enum.md`：#why-sqrt の静的な図（staircase.svg）と div の間に、動く図の案内の 1 段落を足した（「同じ N = 20 の階段を左の段から 1 つずつ取り、段の範囲 [l, r] と、和に足す量（段の幅 × 高さ）を示す。右端 r の求め方は次の節で説明する。8 段を足し終えると和は 66 になる」）。図は右端の式 r = ⌊N/q⌋ を先に使うので、#block-end へのリンクで補った。div の config は執筆者のまま

## config

`{"n": 20}`（本文と同じ。変えていない）

- `n`：正の整数 N（1〜30）。30 を上限にしたのは、幅 360px で棒（最小 11 単位）と値の文字が見分けられる本数にとどめるため
- 誤りは見本と同じく Error を投げ、viz.js が「図を表示できなかった：…」と出す（`n` がない・整数でない・文字列・0 以下・31 以上・NaN・Infinity、config が null）

## ステップ（本文の例で 10 状態）

1. start：階段全体（まだ足していない棒は点線の枠）と √N の縦線。上に「√N ≈ 4.47」、線の左に「1 個ずつ」、右に「商 < √N」
2. block（区間ごとに 1 状態、N = 20 で 8 状態）：いまの区間を太枠で囲み、横軸の下に l と r の三角（幅 1 なら「l = r」）。caption は「l = 7、q = ⌊20/7⌋ = 2、r = ⌊20/2⌋ = 10。和に (10 − 7 + 1) × 2 = 8 を足して 56 になる。l > √N の側なので、商 q = 2 は √N より小さい。次の左端は l = r + 1 = 11。」の形（執筆者の仕様の例と同じ並び）。l ≤ √N の区間には「幅 1 の区間である」と書く。足し終えた区間は塗る
3. done：「l = 21 > N なので終わる。区間は 8 個（√N より左に 4 個、右に 4 個）で、Σ ⌊20/i⌋ = 66 である。」

値（q）は各段の上に書く。図の下の行に「足した区間 k 個、和 = …」を出す。√N の縦線は棒 s と s + 1 の境目に引く（s = ⌊√N⌋）。平方数の N では「√N = s」と書く。

色だけに頼らないよう、まだ足していない棒は点線の枠、足し終えた棒は実線と塗り、いまの区間は太枠と l・r の三角と太字の値で区別した。

## 未解決の点

- 幅 360 では添字（12px）が約 10px、上の区別の文字（13px）が約 11px になる。見本と同じ程度なので、そのままにした
- 幅 1 の段の 2 桁の値（「10」など、16px）は棒の幅 17 単位よりわずかに広く、隣の段の枠に少しかかる。高さが違うので読めると判断した
- 図は #why-sqrt にあるが、右端の式は次の #block-end で導く。案内の段落でリンクしたが、図を #block-end に移すかはメインの判断に任せる（本文の流れは変えていない）

## 検証の指摘への対応

検証（`verify-floor-quotient-enum.md`）は直すべき 0 件・直すとよい 2 件。2 件とも採った（採らなかったものはない）。

- 1（start の caption の言い回し）：「右（i > √N）は値が √N 未満しかない」を「右（i > √N）の値はどれも √N 未満である。」に替えた

- 確かめたこと：`node --test` 7 件通る、`check_pages.py` エラー 0・警告 0、textlint エラー 0（警告 20 は以前からの行）。ビルドし直して幅 360 で本文の例（1/10・2/10・8/10・10/10、End・←）と config `{"n": 1}` を撮り、新しい caption・図・ステップ送りを目で確かめた。JS の例外 0、はみ出しなし
