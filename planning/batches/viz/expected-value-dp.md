# 動く図 expected-value-dp の報告

## 作ったもの

- `overrides/assets/js/viz/expected-value-dp.js`：期待値 DP を終状態から後ろ向きに埋める図。前半は HP の例、後半は自己ループのあるすごろく
  - 前半（hp）：HP n … 0 を左から右へ並べる。HP − 1 へは実線の矢印、HP − 2（HP 1 からは HP 0）へは破線の弧。HP 0 に 0 を書き、1 ステップごとに 1 状態ずつ $E[h] = 1 + pE[\max(h-2,0)] + (1-p)E[h-1]$ を当てはめる。caption に記号の式と数を入れた式、値（分数と小数）を書く
  - 後半（sugoroku）：マス 0 … N−1 を並べ、1〜A_i 進む矢印（隣は直線、ほかは上の弧）と、0 の目の自己ループ（箱の下の輪）を描く。各マスで「移項前の式」（値は ? のまま）と「移項後の式と値」の 2 ステップにした
  - 値は BigInt の分数で正確に計算する。箱の中は小数で書き切れれば小数（2.875）、そうでなければ分数（17/6）
  - 色だけに頼らない工夫：まだ決まっていない状態は「?」、いま式を当てはめる状態は太枠と下の印（「計算」「移項前」「移項後」「E = 0」の文字）、答えは塗りつぶし。矢印の種類は実線・破線・下の輪で区別し、凡例を言葉で書いた。いま見ている状態から出る矢印だけを太く、ほかを薄くする
- `tests/viz/expected-value-dp.test.mjs`：7 件
  - 本文の config で前半の値が 0・1・1.5・2.25・2.875（23/8）、後半が 17/6・5/2・2・0（`snippets/expected-value-dp/self-loop.cpp` の入力「4 / 3 2 1」の出力 2.8333333333 と同じ）になる。caption に本文と同じ式が出る
  - 移項前の状態では値が未定で右辺に自分自身があり、移項後の状態で値が決まる
  - 不変条件：決まった値は変わらない、1 ステップに決まる値は 1 つまで、値は終状態の側から連続して決まる、caption が空でない
  - ランダムな config 300 通りで、漸化式を使わない素朴な方法（確率の分布を前に配り、終わった時点の回数に確率を掛けて足す）と一致する
  - 端の場合：p = 0（E[h] = h）、p = 1（⌈h/2⌉）、HP 1、A がすべて 1（2 × 残りのマス数）、A = [1]、片方の部分だけの config
  - 同じ入力から同じ列ができ、入力を書き換えない。不正な config 16 通りで Error を投げる。viewBox

## 検証の指摘への対応（verify-expected-value-dp.md）

直すべき指摘は 0 件。直すとよい 4 件はすべて直した。

1. 箱からはみ出す分数：`shortText` で、小数か分数が 6 文字を超えるときは小数 2 桁の近似（`≈5.44`）を箱に書き、分数は caption だけにした。config の範囲（n ≤ 7・分母 ≤ 100）は変えていない。試験に「すべての HP の config（n = 1〜7、分母 ≤ 100）とすべてのすごろくの config で箱の文字列が 6 文字以下、近似は値と 0.005 以内」を足した。本文の config は近似を使わない（試験で確かめる）
2. すごろくの凡例を「右向きの矢印（横と上）：1〜A_i の目で進む」にした
3. p = 0 では凡例の破線の行と caption の「HP t2」を、p = 1 では実線の行と「HP t1」を省いた（HP 1 の caption も「1 のダメージで」「2 のダメージで」に分けた）。試験を足した
4. 弧の端：入る弧は箱の上辺の左半分、出る弧は右半分に、本数に応じて均等に並べ、長い弧ほど外側（入る側は右、出る側は左）に置いて弧どうしが交わらないようにした。強調する矢印はほかの矢印の後に描き、上に重なるようにした。A = 6, 5, 4, 3, 2, 1 でもゴールの上の矢じりは 1 本ずつ見分けられる（間隔は約 4 px なので、詰まってはいる）

確かめたこと：`node --test tests/viz/expected-value-dp.test.mjs` 9 件・`tests/viz/*.test.mjs` 全体が通る。`check_pages.py` エラー 0・警告 0。textlint は前からの 23 件のみ（ページは変えていない）。ビルドしたサイトを chrome-headless-shell で開き、本文の config（幅 800 ライト・360 ダーク）と `{"hp":{"n":7,"p":"1/100"}}`・`{"hp":{"n":3,"p":0},"sugoroku":{"a":[6,5,4,3,2,1]}}`・`{"hp":{"n":7,"p":"1/3"},"sugoroku":{"a":[2,4,3,2,2,1]}}` で、ステップ送りで値と caption が進むこと、箱の文字が箱に収まること、console にエラーがないことをスクリーンショットで確かめた。
