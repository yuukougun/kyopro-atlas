## 気づいたが指摘にしないこと

- 既定の配置で頂点・辺が多いと、辺が交わって数がほかの辺の線や頂点に重なる（頂点 8・辺 12 の config を幅 390 で撮った。乱数の config では多い）。試験は数が「自分の線」に重ならないことだけを見る。本文の config では重ならないので指摘にしない。多い config を使うときは pos を渡すことを、JS の頭の説明に 1 行足してもよい
- JS の頭の「本文での書き方」の例（6〜7 行）は、a → b の辺と paths のない別のグラフである。正しい config なので害はないが、本文の div と同じにしておくと写すときに迷わない
- 流す状態では道の線を太くせず、変わった数を太字の「前→後」にし、下の行の増加路を普通の字にしている。どの辺が変わったかは数で分かるので、このままでよい
- caption の長さが状態ごとに違うので、操作の列の高さが動く（図の枠の高さが幅 390 で 460〜580px、1280 で 480〜528px）。viz.js・kp.css の共通の作りによるもので、ほかの図も同じなので、この図の指摘にしない（verify-convolution-naive.md と同じ提案）
