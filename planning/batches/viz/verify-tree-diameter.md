## 未解決の点への意見（報告の「未解決の点」）

- 重みのある木に対応しない件：本文の図の例は重みなしで、catalog の visual も重みを求めていない。今のままでよい
- 並べ直した図の上下の余白：真ん中に置かれていて、撮った画像で不自然ではない。直さなくてよい
- 線の色を `style` に Material の CSS 変数で書く件：ダークでも読めることを確かめた。lca と同じ扱いでよい
- caption の長さでボタンが上下する件：ほかの図と同じで、直さなくてよい
- 付記：並べ直した図は枝の葉の数で列を割り当てるので、枝の多い頂点の前後で直径の頂点の間隔が不ぞろいになる（上の 8 頂点の例で 3–0 と 0–5 の間が広い）。長さは目盛りの文字で示されており、誤りではないので指摘にはしない
