直すべき指摘は 0 件、直すとよい指摘は 5 件。状態の列は手法として正しく、本文とも食い違わない。

## 確かめたこと

- **試験**：`node --test tests/viz/two-pointers.test.mjs` → 8 件すべて通る。試験は、各状態で保つ性質（和が区間の中身と一致・0 ≤ l ≤ r ≤ N・端が戻らない・at-most では和 ≤ K）と、最後の状態（全探索の r(l)・区間の数）を両方確かめている（G1 の「状態の数だけ」の失敗はない）
- **自分で書いた突き合わせ**（scratchpad の `tpv/v.cjs`、リポジトリには置いていない）：累積和から各 l の r(l) を直接求める別の方法と比べた。乱数 40000 通り（値 0〜3 と 0〜99 を混ぜる。N = 1〜12、at-most は K = 0〜59、at-least は K = 1〜200）と、値 0〜3・N ≤ 5・K ≤ 9 のすべての列、合わせて 65916 通りで r(l) と区間の数が一致した。あわせて次の点も確かめ、すべて合った
  - 1 ステップの変化は 1 つだけ：extend は r だけ +1、decide は r(l) の 1 点だけを決める、advance は l だけ +1（空区間のときだけ r も +1）、none・done は何も動かさない
  - caption に書いた r・r(l)・l の値が、その状態の値と一致する
  - at-most の decide で ×（next）を付けた要素は、入れると本当に和が K を超える
- **本文の例**（A = (1, 2, 1, 3, 1, 1, 2)、K = 4）の 22 状態の caption を 1 つずつ手で追った。r(l) = 3, 3, 4, 5, 7, 7, 7、区間の数 15 で、静的な図 window-staircase.svg の帯の右端・本文の $r - l$ の数え方と一致する
- **本文の段落**：「伸ばせなくなったら r(l) を決めて左端を進める」「どのステップでも和が 4 以下」「右端は戻らない」「折れ線に 1 点ずつ足す」「15 個」は、いずれも状態の列と一致する
- **ページの検査**：`python3 tools/check_pages.py` → 警告 0。エラー 5 件はすべて `dp/dp-phase.md` の問題の一覧の書式で、このページとは関係ない（two-pointers の行は 0 件）
- **textlint**：`npx textlint docs/basics/two-pointers.md` → エラー 0・警告 25。HEAD の版でも 25 で、足した段落（75 行）からは出ていない
- **ビルド**：`uv run mkdocs build -d …/scratchpad/site-two-pointers`（-q なし）。警告は `dp/dp-dimension-reduction.md` のアンカー 1 件だけで、このページとは関係ない
- **ブラウザ**：chrome-headless-shell 146.0.7680.76 を CDP で操作（日本語は font_env と同じく /mnt/c/Windows/Fonts を足した fontconfig）。ビルドを `python3 -m http.server` で配って開いた
  - 幅 360・ライトと、幅 1000・ダーク（slate）で、図が 1 つ取り付き、JS のエラーはない。「次へ」で 1 → 5 → 6 → 10 → 17 → 22 / 22 と進み、caption・枠・r と l の三角・破線のマスと ×・折れ線の点が状態どおりに変わることを目で確かめた。Home → → で 2 / 22 になる。最後のステップでは「次へ」「最後へ」が無効になる
  - 幅 360 で横スクロールなし（scrollWidth 360）。図の SVG は幅 307px（viewBox 360 → 0.85 倍）で、数字は読める。ボタンは 44×44px
  - ダークでも枠・点・三角が見える。出したマスと未処理のマスは塗りの濃さの差が小さいが、l の三角の左か右かで区別できる
  - 試しのページ（ビルドの複製に div を足したもの）で、at-least の例（20 状態、none のステップで [5, 7) 和 3 < 4）、N = 12・値 99、K = 0 で l と r が一緒に進む例も描けることを確かめた
- **config の誤り**：K = −1（at-most）、mode = "exact"、JSON の誤り（引用符のない鍵）の 3 つで、それぞれ「図を表示できなかった：…」の文が出て、変な図は描かれない。試験でも data-config なし・array の長さ/値・K・mode の誤りで Error を投げることを確かめている
- **色だけに頼っていないか**：区間は太い枠、断った要素は破線の枠と ×、出した要素は薄い塗りと l の三角より左の位置、いま決めた点は大きさ（半径 6 と 4）と値の数字で区別しており、色だけには頼っていない
- 試していないこと：instant navigation で別のページへ移って戻る操作、スワイプ、自動再生（viz.js の共通の部分で、この図の範囲ではないため）
