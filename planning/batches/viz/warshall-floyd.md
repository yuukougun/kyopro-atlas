## 動きとステップ

- `"kij"`：初期（辺だけの表）→ 各 k の段の始まり → 段の中で i ≠ j かつ i, j ≠ k のマスを行の順に 1 つずつ（`d[i][j] = min(d[i][j], d[i][k] + d[k][j])`）。k 行目・k 列目・対角は段の中で変わらないので飛ばし、段の始まりの caption でそう述べる。本文の例は 29 状態
- 各マスの caption：候補の式と結果（∞ を経由するときは「d[0][2] が ∞ なので、頂点 0 を経由しても届かない」、等しいときは「と同じなので、…のまま」）。段の最後のマスに「k = 1 の段で変わったのは d[2][0]・d[2][3] である」、最後の状態に「表は全点対の最短距離である」
- 本文の箇条書き（k = 0：d[1][3] = 3、k = 1：d[2][0] = 3・d[2][3] = 4、k = 2：d[3][1] = 2・d[3][0] = 4、k = 3：d[0][2] = 2・d[0][1] = 5 → 3・d[1][2] = 4）と最後の表に一致する
- `"ijk"`：初期 → i ≠ j のマス (i, j) を行の順に 1 つずつ（k を内側で回した候補をまとめて 1 ステップ。式は `d[0][1] = min(5, ∞ + 1, 1 + ∞) = 5`）。最後に正しい表と違うマスを `wrong` に入れ、× と「正 3」を描き、caption で「d[0][1] が 5（正しくは 3）」と述べる。本文の例は 13 状態で、確認問題の答え（d[0][3] + d[3][1] の d[3][1] がまだ ∞、d[0][2] + d[2][1] の d[0][2] もまだ ∞）と同じ候補が出る
- 描画（色だけに頼らない）：左に小さいグラフ、右に N × N の表、下に式の 1 行と凡例 2 行
    - 中継点 k：表の k 行目・k 列目を塗り、見出しを太字の「k=3」にする。グラフの頂点 k を塗り、斜体の「k」の印
    - 比べるマス (i, j)：太い枠。グラフの頂点 i と j に輪と「i」「j」の印
    - 足す 2 マス d[i][k]・d[k][j]（ijk では候補のマスすべて）：破線の枠
    - 今回の更新はマスに「5→3」（太字）。この段（ijk ではこれまで）に更新したマスは右上に三角
    - 式の 1 行は更新のとき太字で「（更新）」が付く
