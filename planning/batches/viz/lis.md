# 動く図 lis（最長増加部分列）

## 作ったもの

- `overrides/assets/js/viz/lis.js`：LIS の二分探索版で、長さごとの末尾の最小値 L が 1 か所ずつ変わる様子の図
  - 上段：列 a（添字 i つき）。いま入れる要素は太い枠と上の三角「x」で示し、まだ見ていない要素は薄くする
  - 中段：dp[i]（a[i] で終わる最長）。まだ決まっていないマスは破線。update の状態では、いま決まった dp[i] を濃い塗りにし、素朴な O(N^2) の DP で比べる相手（a[j] < a[i]、広義なら ≤ となる左の j）を薄い塗りと下の小さな丸で示す（色だけに頼らない）
  - 下段：L（添字 k つき）。位置 k は下の三角「k」で示す。find では置き換える箱を太い枠に、追加なら末尾に破線の「追加」の枠を出す。update では置き換えた箱を濃い塗りにし、上に「4→2」のように前後の値（追加なら「追加」）を書く
  - いちばん下に「|L| = 4　狭義・lower_bound」
  - 状態：start → 各要素について find（二分探索で k を求める。L は入れる前）・update（置換か追加の後）→ done。N = 8 で 18 状態。caption はだ・である調で、find は「L = (1, 4, 5, 9) の中で 2 以上の最初の位置は k = 1（L[1] = 4）である。」、update は置換・追加と、k + 1 が素朴な DP の dp[i]（左の dp[j] の最大 + 1）と一致することを書く。値が同じ置換には「（値は変わらない）」、done は「LIS の長さは L の要素数の 4 で、dp の最大 4 と一致する。L = (1, 2, 5, 6) は…元の列の部分列とは限らない。」
  - k は番兵（−1 と |L|）の二分探索で求める（狭義は L[k] ≥ x、広義は L[k] > x の最初）
- `tests/viz/lis.test.mjs`：7件
  - 本文の例：位置 k = 0, 0, 1, 0, 2, 3, 1, 3、置換前の値（null, 3, null, 1, null, null, 4, 9）、入れた後の L が本文の表と一致、dp = 1, 1, 2, 1, 3, 4, 2, 4 が素朴な DP と一致、長さ 4、「値は変わらない」の caption
  - 確認問題 (1, 1, 1)：狭義は L = (1)、広義は L = (1, 1, 1)
  - 端の場合：1 要素、減少列（毎回 k = 0）、増加列（毎回追加）、負の値（caption は「−3」）、strict の省略は狭義
  - ランダム 3000 通り × 狭義・広義：L の長さが部分列の全探索の LIS と一致、k + 1 が素朴な DP と一致、find と update の差が位置 k の 1 か所だけ、どの状態でも L が昇順、状態の並び
  - 決定的であること・入力を書き換えないこと・入力の誤り・viewBox（N = 8 で幅 404）
