## 指摘

### 1. 直すべき｜事実（F2）｜#monotone-minima の「自作するときの要点」3 つ目の括弧「（区間の種類数など）」

- **問題**：最小化の区間分割 DP で、$O(1)$ で求められないコストの例に「区間の種類数」を挙げているが、区間の種類数は Monge でない（不等号が逆向きの「逆 Monge」）。読者は「種類数の和を最小にする K 分割」に分割統治 DP を使ってよいと読む
- **根拠**：列 $x = (0, 1, 0)$、$a=0, b=1, c=2, d=3$ で、$c(0,2) + c(1,3) = 2 + 2 = 4 > c(0,3) + c(1,2) = 2 + 1 = 3$。プログラムでも「種類数」は Monge でなく「−種類数」が Monge と出た（値が $[a,b)$ と $[c,d)$ だけに出ると、左辺に 2、右辺に 1 効く）。一方、区間の中の同じ値の組の個数は Monge（外側と内側の差が「$[a,b)$ と $[c,d)$ にまたがる組の数」$\ge 0$）
- **直し方**：例を「区間の中の同じ値の組の個数など」に替える。種類数を残すなら「種類数の和を最大にする場合（−種類数が Monge）」と向きを書く

### 2. 直すとよい｜事実（F2）・分かりやすさ（U2）｜#monotone-minima の「自作するときの要点」2 つ目（同じ値のとき）

- **問題**：「最も左を残す（または最も右を残す）と決めて、全体でそろえる」とあるが、Monge な行列では選び方をそろえなくても値は正しい。執筆者の未解決の点 4 への答えになる
- **根拠**：行 $i_1 < i_2$ の最小の位置 $j_1, j_2$ が $j_2 < j_1$ なら、Monge の不等式と最小性から $A[i_1][j_2] + A[i_2][j_1] = A[i_1][j_1] + A[i_2][j_2]$ となり、$j_2$ も行 $i_1$ の最小、$j_1$ も行 $i_2$ の最小である。よって真ん中の行でどの最小の位置を選んでも、上下の範囲に最小が残る。乱数で選ぶ実験（3000 例）でも全部正しかった。そろえる必要があるのは、Monge でなく「最小の位置が単調」とだけ分かっている行列（同じ値の扱いで単調性が崩れうる）の場合
- **直し方**：「Monge なら、同じ値のときにどれを選んでも値は正しい（証明の折りたたみに 1 文足せる）。最小の位置の単調性しか分かっていない行列では、最も左（または最も右）にそろえる」とする

### 3. 直すとよい｜分かりやすさ（U3）｜#definition の 2 段落目と箇条（「$a \le b \le c \le d$ について $c(a, c) + \dots$」）

- **問題**：$c$ がコストの関数名と添字の両方に使われていて、「$c(a, c)$」「$c(b, c)$」が読みにくい。さらに #convex-max-plus-convolution では $c_k$ が畳み込みの結果の列になる
- **根拠**：レート 1000 前後の読者が最初に読む定義の式で、$c(a,c)$ の 2 つの $c$ が別物であることの説明がない
- **直し方**：本文の添字を $a \le b \le x \le y$（または $l_1 \le l_2 \le r_1 \le r_2$）などに替えるか、コストを $w(l, r)$ と書く（Knuth-Yao の節は既に $w$）。signs の文言は front matter なので変えず、本文だけ直せばよい

### 4. 直すとよい｜分かりやすさ（U3）｜#convex-max-plus-convolution の 1 段落目

- **問題**：「一般には $O(NM)$」「$O((N + M) \log (N + M))$」の $N, M$ が、この節では定義されていない。#definition・#monotone-minima では $N$ 行 $M$ 列の意味だったので、行の数（$N + M - 1$）と取り違えやすい
- **根拠**：節を単独で読む（U6）と $N, M$ が何か分からない。コード片は `n = a.size(), m = b.size()`
- **直し方**：「長さ $N$ の列 $a$ と長さ $M$ の列 $b$ の (min,+) 畳み込みは…」と冒頭で定める

### 5. 直すとよい｜分かりやすさ（U7）｜#practice の練習の方針、ABC383 G

- **問題**：「左端と右端で使えない位置がいくつあるか」ごとに列を持つと状態が $K^2$ 個になるが、それで間に合う理由（$K$ が小さいこと）が書かれていない。また、合成は差分のマージを境目の使えない個数の組ごとに行い、その最大を取るので、「差分のマージで行える」だけだと 1 回のマージで済むように読める
- **根拠**：kmjp 氏のコードは状態を `[5][5]` で持ち、境目の分け方 $j$ と $K-1-j$ ごとにマージしてから要素ごとに最大を取っている（$K$ の上限は問題文を開けないので確かめていない）
- **直し方**：「$K$ が小さいので、両端の使えない個数の組ごとに列を持てる」「境目で使えない個数の分け方ごとにマージし、要素ごとの最大を取る」を足す。$K$ の上限はメインが別の解説で確かめる
