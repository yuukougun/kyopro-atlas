## 指摘

### 1. 直すべき｜事実（F2）｜#surreal「自作するときの要点」の 1 つ目

- 問題：「値の分母の指数は、その局面から続けられる手数の最大より小さい」の「続けられる手数」は、ふつうに読むと交互に打つときの手数になる。そう読むと偽である。
- 根拠：茎 BRRRR（地面から実線 1・破線 4）の値はコード片で 1/16（d = 4）。交互に打つと、左が先なら 1 手、右が先なら破線を 1 本切った後に左が実線を切って 2 手で終わり、最大 2 手で d = 4 より小さい。成り立つのは、手番を問わず続けて打つ手の数の最大（局面の木の深さ）で数えたときである（m/2^d（d ≥ 1）の誕生日は d + 1 以上で、値の誕生日は局面の木の深さ以下）。和の中では同じ部分で片方が続けて打つことがあるので、深さで数えるのが正しい。執筆者の未解決の点 1 の答えでもある。
- 直し方：「値の分母の指数は、その局面から（手番を問わず）続けて打てる手の数の最大、つまり局面の木の深さより小さい」と書く。Hackenbush の茎なら辺の本数で見積もれる、と添えると具体的になる。

### 2. 直すべき｜分かりやすさ（U7・手引き §10・§14-23）｜#tempo の最後の段落

- 問題：本文が練習の ABC265 Ex を指したうえで、「向かい合う 2 つの駒の間の空きは Nim の山、背中合わせの駒の前の空きはパスの貯金」と解き方の核を折りたたみの外に書いている。checklist の U7 が挙げる失敗（本文が練習の問題を指して、その解き方を折りたたみの外で書く）にあたり、練習の方針の折りたたみが意味をなさなくなる。
- 根拠：clarity.md U7、style-guide §10（練習の方針は一覧の後の折りたたみに書く）。
- 直し方：段落を一般的な形（「両者が同じ手を打てる部分と、相手と関わらずに打てる手が混ざる盤面に現れる」程度）にとどめ、具体的な対応（向かい合う駒・背中合わせの駒）と練習問題へのリンクは「練習の方針」の折りたたみに任せる。

### 3. 直すとよい｜事実（F5）｜例題 ABC229 H の解法の詳細の 3 つ目

- 問題：「N ≤ 8 では 2^6 ほどで足りると kmjp 氏の記事にある」とあるが、記事にあるのは「問題の条件では q は 6 程度にしかならない」だけで、N ≤ 8 は記事の文にない（記事のコードの配列の大きさから推せるだけ）。
- 根拠：https://kmjp.hatenablog.jp/entry/2021/12/01/0930
- 直し方：「この問題の制約では分母は 2^6 ほどで足りると kmjp 氏の記事にある」とする。

### 4. 直すとよい｜事実（F9）｜#resources の 3 つ目

- 問題：邦訳名『組合せゲーム理論入門 勝利の方程式』は執筆者も書誌を確かめておらず（未解決の点 4）、検証でも検索では著者・出版社つきの書誌を確かめられなかった。原書は Albert・Nowakowski・Wolfe『Lessons in Play: An Introduction to Combinatorial Game Theory』（A K Peters、第 2 版あり）であることは確かめた。
- 直し方：出版社か国立国会図書館の書誌で確かめられたら邦訳名を残し、確かめられなければ原題と著者だけにする。

### 5. 直すとよい｜分かりやすさ（U3）｜#why-not-grundy の最後の段落

- 問題：「上の 3 つの和は 1・0・1」の「3 つ」が、箇条書き 3 行（1 行目は A と B の 2 つを扱う）と数が合わず、どれを指すか一瞬迷う。
- 直し方：「$A$、$A + B$、$A + A + B$ の値は $1$・$0$・$1$ になり」と明示する。
