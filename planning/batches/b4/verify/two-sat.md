## 指摘

### 1. 直すべき｜事実（F2・F5）・分かりやすさ（U7）｜#practice の「方針」（ABC277 Ex の和の下限）

- **問題**：「和の下限は『$X_a < k$ なら $X_b \ge L - k$』」は 1 ずれている。この節では $X_a + X_b \ge L$ を表せず、$X_a + X_b = L - 1$ の割当を通してしまう
- **根拠**：$X_a = k - 1$ のとき、この節は $X_b \ge L - k = L - 1 - X_a$ しか強制しない。たとえば $(X_a, X_b) = (0, L - 1)$ は、どの $k$ の節（と対偶）も満たすが、和は $L - 1$ である。小さなプログラムで確かめた。$M \le 5$ と $0 \le L \le 2M$ のすべてについて、全節を満たす $(X_a, X_b)$ の集合を「和 $\ge L$」と比べた。本文の式では 30 通りの $(M, L)$ で食い違った。$X_b \ge L - k + 1$ に直すと、どの $(M, L)$ でも一致した（$k = 1, \dots, M + 1$ の範囲で、範囲の外の $y$ は真か偽に固定した）。kmjp 氏の記事（evidence）のコードも、下限側は $V(A, k) \lor V(B, L - k + 1)$ を使っている。上限の「$X_a \ge k$ かつ $X_b \ge R - k + 1$ は禁止」は正しい
- **直し方**：「和の下限は『$X_a < k$ なら $X_b \ge L - k + 1$』」に直す。下限と上限で $+1$ がそろうので、読者が取り違えにくくもなる

### 2. 直すとよい｜分かりやすさ（U3）・事実（F7）｜#cheatsheet の表の「ACL での書き方」の列

- **問題**：ACL の列は、$a$ が「$x_i$ が真」で $b$ が「$x_j$ が真」のときの書き方である。表の前の文はこの対応を書いていない。リテラルが $\lnot x_i$ のとき（例：「カード $i$ が裏」）も表をそのまま写すと、`f`・`g` の真偽が逆になる。本文が「最も多い誤り」と書く、真偽の取り違えそのものである
- **根拠**：ACL の `add_clause(i, f, j, g)` は $(x_i = f) \lor (x_j = g)$ を表す。$a = (x_i = \text{false})$ なら、「$a$ と $b$ は同時に選べない」は `(i, true, j, false)` になる
- **直し方**：表の前の文に「ACL の列は $a$ を $x_i$ が真、$b$ を $x_j$ が真としたときの書き方。リテラルが否定なら、その側の `true`・`false` を入れ替える」と足す

### 3. 直すとよい｜事実（F7）・分かりやすさ（U4）｜#acl の最後の段落（Library Checker の入力）

- **問題**：「入力のリテラル $k$ は $x_k$ を、$-k$ は $\lnot x_k$ を表す」とあるが、DIMACS の変数は 1 から $N$ までである。本文の変数は $x_0, \dots, x_{N-1}$ なので、そのまま読むと添字がずれる。出力も `s SATISFIABLE` と `v x_1 … x_N 0` の形（真なら $i$、偽なら $-i$）で、`Yes` と 0・1 の列ではない
- **根拠**：library-checker-problems の other/two_sat/task.md
- **直し方**：「変数は 1 始まりなので、$k$ を $x_{k-1}$ に読み替える。出力は `s SATISFIABLE` の行と、各変数を $\pm i$ で並べて 0 で終える行」と 1 文足す

### 4. 直すとよい｜事実（F2）｜#when-to-use の箇条書き 1 つ目・3 つ目

- **問題**：(a)「3 つ以上のリテラルの OR が必要なものは 3-SAT と同じ形で、多項式時間の解き方は知られていない」は、問題ごとに言うと言い過ぎである。一般の 3-SAT は NP 完全だが、3 リテラルの節を含む個別の問題が解けないとは限らない（構造を使って別の解き方がある場合がある）。(b)「条件を破るたびにコストがかかり、その和を最小にしたいなら燃やす埋める」も、燃やす埋めるが扱えるのは劣モジュラなコストの形に限られる。2 変数のどんな条件のコストでも扱えるかのように読める
- **根拠**：(a) NP 困難は一般の 3-SAT についての主張である。(b) 燃やす埋めるは、最小カットで表せる形（「$a$ が真で $b$ が偽ならコスト」の型）に限られる。重みつきの 2-SAT（MIN 2-SAT など）は一般に NP 困難である
- **直し方**：(a)「一般の 3-SAT は NP 困難で、2-SAT のようには解けない」とし、使えない理由を形の一般性に置く。(b)「コストの形が燃やす埋めるの型に合えば、燃やす埋めるを考える」と条件を添える

### 6. 直すとよい｜分かりやすさ（U3）｜#implication の第 3 段落「この対称性が、次の節の復元の正しさを支える」

- **問題**：次の節の背理法が使うのは、各節の 2 本の辺 $\lnot a \to b$・$\lnot b \to a$ だけである。パスの対称性（$u \leadsto v$ なら $\lnot v \leadsto \lnot u$）は使わない。読者は、証明のどこで対称性を使うのか探して迷う
- **根拠**：#unsatisfiable の不等式の連鎖は、節の 2 本の辺から直接出る
- **直し方**：「復元の正しさは、節ごとに 2 本の辺が両方あることに依る（次の節の背理法で 2 本とも使う）」のように、2 本の辺そのものを指す言い方にする。パスの対称性は直感の補足として残してよい

### 7. 直すとよい｜分かりやすさ（U10）｜#unsatisfiable・#at-most-one の証明

- **問題**：手引き §4 は、overview（発展）について「短く書き、証明や実装の流れは資料に任せる」としている。このページは、復元の背理法と「高々 1 つ」の正しさの議論を本文に書いている。どちらも数行で読みやすく、誤りもない（上で確かめた）。ただし、型の約束からは少し外れる
- **根拠**：style-guide.md §4 の overview（発展）
- **直し方**：今のままでもよい。短くするなら、背理法の段落を `??? note "割当が節を満たす理由"` に折りたたみ、本文には直感の段落だけを残す
