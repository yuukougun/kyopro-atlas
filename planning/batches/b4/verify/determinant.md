## 指摘

### 1. 直すべき｜事実（F2）・確認問題（U8）｜#quiz「行を入れ替えずに済ませるには」の答え

- **問題**：「ただし mod $m$ では、足した結果がちょうど $m$ の倍数になって再び 0 になることがある」は誤り。$a_{cc} \equiv 0$ のところに $a_{rc} \not\equiv 0$ を足すので、和は $a_{rc} \not\equiv 0$ であり、0 になることはない
- **根拠**：$0 + a_{rc} \equiv a_{rc} \pmod m$。整数の代表 $[0, m)$ で持っても $0 + a_{rc} = a_{rc} \in (0, m)$
- **直し方**：その文と「入れ替えの方が確実である」を消し、「mod $m$ でも、0 に 0 でない値を足すので 0 にはならない。手間は入れ替えと同じ $O(N)$ で、どちらを使ってもよい（入れ替えなら符号の反転を忘れないこと）」のように書く。条件を外すと何が起きるかを問いたいなら、「足す行を見つけるのに 0 でない行を探すのは入れ替えと同じ」など別の観点にする

### 2. 直すべき｜事実（F2）｜#applications の LGV 補題の行

- **問題**：「互いに頂点を共有しない経路の組の数を、…行列式で求める」と、符号付きであることの条件が落ちている。行列式が一般に与えるのは置換の符号付きの和で、交わらない組が恒等置換でしか作れないとき（平面的な並びなど）にだけ個数に等しい
- **根拠**：lgv-lemma の summary と要点は「（符号付き）」「（置換の符号付き）」と書き、同ページの確認問題に $\det M = -3$ になる例がある。条件の書き落としはチェックリスト F2 の「よくある失敗」そのもの
- **直し方**：「…経路の組の数（置換の符号付き。交わらない組が恒等置換でしか作れないように番号を付ければ個数そのもの）を、…行列式で求める」のようにする

### 3. 直すとよい｜事実（F2）｜#library「0 を返す条件」と #pitfalls「法が素数でないのに逆元を使う」

- **問題**：どちらも「誤った値になる」とあるが、ACL の modint では `inv()` が `assert` で止まる（素数の法では `assert(_v)`、そうでなければ `assert(gcd == 1)`）。誤った値になるのは、フェルマーの小定理の `pow(x, p-2)` などを自作して 0 や逆元のない数に使った場合である
- **根拠**：~/lib/ac-library-master/document_ja/modint.md の `x.inv()` の制約「`gcd(x.val(), mod) = 1`」、atcoder/modint.hpp の `inv()` の実装
- **直し方**：「ACL の modint なら assert で止まり、自作の累乗で逆元を求めていれば誤った値になる」のように両方を書く

### 4. 直すとよい｜事実（F2）｜#applications の行列木定理の行

- **問題**：ラプラシアン行列の対角を「各頂点の次数」とだけ書いている。自己ループを次数に数える（ふつうは 2 を足す）と答えがずれる
- **根拠**：matrix-tree-theorem#laplacian の本文は「自己ループは全域木に使えないので行列に入れない」と断っている
- **直し方**：「対角に各頂点の次数（自己ループを除く）」とする。多重辺は本数をそのまま数えることも一言添えると、matrix-tree-theorem と揃う

### 5. 直すとよい｜分かりやすさ（U2・U3）｜#modulus の「計算量」の段落

- **問題**：「対数は打ち消し合って $O(N + \log m)$ になる」の一文で、なぜ打ち消し合うかが読者には見えにくい。1 行あたりの回数が $\log(\text{前のピボット} / \text{後のピボット}) + O(1)$ で、それを足すと途中の項が消える、という式がない
- **根拠**：上の「実行して確かめたこと」の議論のとおり、主張自体は正しい
- **直し方**：「行 $r$ の処理の前後のピボットを $p_{r-1}, p_r$ とすると回数は $\log(p_{r-1}/p_r) + O(1)$ 程度で、$r$ について足すと $\log(p_c/p_{N-1}) + O(N) \le \log m + O(N)$ になる」と式で 1 文書く
