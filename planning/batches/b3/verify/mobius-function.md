### 執筆者の未解決の点について

- **abc230_g の i ≤ j**：i ≤ j（i = j を含む）である。根拠は 2 つ。(1) kmjp の記事は問題の要約の行に「1≦i＜j≦N」と書くが、使っている式は Σ μ(a)μ(b)·g(g+1)/2 で、上の chk.py のとおりこの式は i ≤ j の個数を数え、i < j の個数とは一致しない（差は i ≥ 2 かつ P_i ≥ 2 の i の数）。解答コードがこの式で通っているので、問題は i ≤ j である。(2) Web 検索の結果の要約で、ikatakos の記録が「1 ≤ i ≤ j ≤ N」としている（問題文を引用した節は開いていない）。Kodaman は c² の順序対で書いており、どちらとも矛盾しない
- **abc230_g の N の上限**：kmjp の解答コードの配列の大きさ 202020 と、Kodaman の「N 以下の整数の素因数の種類は 6 個以下」から、N ≤ 2×10^5 と見てよい（6 個以下は 30030 ≤ N < 510510 と合う）
- **agc039_c の周期の包含**：「回数が 2d の約数になる k の個数 F(d) は、回数がちょうど 2e（e | d、d/e は奇数）の個数の和」は正しい（周期 2e の列は、d/e が奇数なら 2d ずらしても戻る。d/e が偶数の e は、そもそも N/e が奇数でないので出てこない）。drken の記事の「N/l が奇数の約数 l について 2l」とも合う
- **杜教篩の O(N^{2/3})**：前計算を N^{2/3} まで篩で行ったときの値として正しい。multiplicative-function のページで出典を付ければよく、このページの直しは要らない
