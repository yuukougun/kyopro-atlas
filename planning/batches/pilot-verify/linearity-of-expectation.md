## 指摘

### 1. 直すべき｜事実｜#pairs の最後から 2 段落目（158 行）

- **問題**：「一部だけがシャッフルされる場合は、ペアを『両方ともシャッフルされる』『片方だけ』『どちらもされない』に分ける」と 3 つに分けながら、「片方だけ」のペアの扱いを書いていない。しかも「一部だけ」と一般に述べているが、片方だけのペアの転倒数の和が変わらないのは、シャッフルする位置が連続した区間のときだけである
- **根拠**：区間の外の要素 $o$ から見ると、区間の位置はすべて $o$ の同じ側にあるので、$o$ と区間の中の値との転倒の数は区間の中の並びによらない（シャッフルしても和は変わらない）。連続でないと崩れる：P = (0, 1, 2, 3) で位置 0 と 2 だけをシャッフルすると期待値は 3/2 だが、「全体 − 中の転倒 + 中のペア数 / 2」は 1/2（小さなプログラムで全数を確かめた）。この段落は練習 ABC380 G の方針（「それ以外のペアは元のまま」）の土台でもある
- **直し方**：「連続した区間 $[l, l+K)$ をシャッフルする場合」と条件を書き、片方だけのペアについて「外の要素 1 つと区間の中の値との転倒の数は、区間の中の並び方によらない（区間の位置がすべて外の要素の同じ側にあるから）。よって和は元のまま」の 1〜2 文を足す。ABC380 G の方針の「それ以外のペアは元のまま」も「区間の外どうし、および外と中のペアの転倒の数の和は元のまま」とする

### 2. 直すとよい｜分かりやすさ（U6・C3）｜#linear-operations のコード片（113〜115 行）

- **問題**：取り込みの 2 行は `seg.prod(l, r).sum` と `F{true, avg}` を使うが、節の中に「節点に（和、長さ）を持ち、作用は『値で上書き』」の説明がない。説明は例題 ABC417 F の折りたたみ（229 行）にだけあり、この節だけを読む読者（claude.ai の断片読みを含む）には `.sum` と `F{true, avg}` の意味が分からない
- **根拠**：手引き §3「節の最初の文で何の話かを書き、前述に頼らない」、clarity U6
- **直し方**：コード片の直前に「遅延セグメント木の節点に（区間の和、区間の長さ）を持たせ、作用 `F{true, v}` を『値 $v$ で上書き』とする」の 1 文を置く

### 3. 直すとよい｜事実（F2）｜#linear-operations の行列の段落（117 行）

- **問題**：「$K$ 回の操作の後の期待値は $\bar A^K E[v]$」は、定数項 $\bar b$ が 0 で、毎回の操作の選び方が同じ分布（独立に同じ確率）のときだけ成り立つ。直前の式は $\bar b_j$ を含むので、そのままでは読者が $\bar b$ を落とす
- **直し方**：「毎回同じ確率で操作を選ぶなら」と条件を書き、$\bar b \ne 0$ なら値の列に定数 1 を足した $(N+1)$ 次の行列にする旨を括弧で添える

### 4. 直すとよい｜事実・分かりやすさ（F2・U3）｜#indicator の 3 段落目（131 行）

- **問題**：連結成分の個数の例で「成分ごとに代表を 1 つ決め、その代表についての指示確率変数にする」とあるが、ランダムな状況では成分そのものが確率的に変わるので、「成分ごとの代表」は候補として固定できない。読者はどう $X_i$ を置けばよいか分からない
- **直し方**：「頂点 $v$ ごとに $X_v = [v \text{ が自分の属する成分で番号が最小}]$ とおく」のように、固定した候補（頂点）ごとの条件として書く。森なら「頂点数 − 辺数」で辺ごとの指示確率変数にする方法も一言添えるとよい

### 5. 直すとよい｜事実（F2）｜#linearity 最後の段落・#nonlinear の表と落とし穴（75・185・195 行）

- **問題**：「積の期待値 $E[XY] = E[X]E[Y]$ には独立性が要る」「独立なときだけ $E[X]E[Y]$」「幅と高さが独立なときだけ正しい」は言い過ぎである。独立は十分条件で、必要条件ではない（独立でなくても $E[XY] = E[X]E[Y]$ となる組はある）
- **直し方**：「独立なら成り立つ（独立でないと一般には成り立たない）」と書き換える。表は「独立なら $E[X]E[Y]$」

### 6. 直すとよい｜事実（F1）｜例題 ABC417 F の解法の詳細（229 行）

- **問題**：各操作で長さの逆元を求める（snippets の `/ (r - l)`）ので、1 操作は $O(\log N + \log p)$ である（ACL の modint の割り算は逆元の計算を伴う）。「各操作 $O(\log N)$」は逆元の前計算を前提にしている
- **直し方**：「逆元を毎回求めても $O(\log p)$ 増えるだけ。$1, \dots, N$ の逆元を前計算すれば各操作 $O(\log N)$」と一言添える。全体の計算量はそのままでよい

### 7. 直すとよい｜分かりやすさ（U3）｜#linear-operations の 1〜3 段落（98〜103 行）
