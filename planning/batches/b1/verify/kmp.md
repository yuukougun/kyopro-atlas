## 指摘

### 1｜直すべき｜fact（F2）｜#pitfalls の「周期はすべて最小の周期の倍数だと思い込む」（244 行）

- **問題**：「最小の周期 $d$ の倍数になると言えるのは、$N - d$ 以下の周期と、$N$ の約数である周期だけ」とあるが、$N$ 自身はいつも周期で $N$ の約数なのに、$d$ の倍数とは限らない。直前の例 $\texttt{aabaa}$ がまさに反例（周期 5 は 5 の約数だが 3 の倍数でない）
- **根拠**：全列挙（$N \le 10$、a・b）で「$N$ の約数である周期が $d$ の倍数でない」例は 1374 件あり、すべて $p = N$。$p < N$ の約数に限ると反例なし（$p \le N/2$ なので $p + d \le N$ で弱周期定理が使える）
- **直し方**：「$N$ 未満の $N$ の約数である周期」にする（または「$N - d$ 以下の周期だけ。$N$ 未満の $N$ の約数はこれに含まれる」とまとめる）

### 2｜直すべき｜fact（F2・F5）・台帳｜#challenge の arc060_d の要約（300 行）と台帳・catalog の summary

- **問題**：「周期を持たない文字列に分割する」とあるが、このページの定義（#string-period、$1 \le p \le N$）では、どの文字列も $p = N$ を周期に持つので「周期を持たない文字列」は存在しない。問題の「良い文字列」は「より短い文字列の 2 回以上の繰り返しで書けない」（本文の言う原始的な文字列）で、方針の折りたたみ（306 行）もその意味で書いている。台帳の approach「各接頭辞・接尾辞が周期を持つかを判定する」も同じ
- **根拠**：drken の記事（evidence）の定義：$y$ と $k \ge 2$ で $y^k$ と書けない文字列が良い。§13.7 により本文の行は台帳から作られる
- **直し方**：報告の「台帳への提案」に arc060_d の summary を「文字列を、より短い文字列の繰り返しで書けない文字列に分割するときの最小の個数と、その分け方の数を求める。」などへ直す案を足す（approach も「…繰り返しで書けるかを判定する」に）。メインが台帳を直して fix_problems を流す

### 4｜直すとよい｜fact（F2）・clarity｜導入（54 行）「$\pi$ は照合に失敗したときのずらし幅を表す」

- **問題**：ずらす幅は $j - \pi[j - 1]$ で、$\pi$ の値そのものは「ずらした後も一致が分かっている長さ（残す長さ）」である。#matching の図の左の文字も「π[3] = 2 だけ残してずらす」で、導入と食い違って読める
- **根拠**：#matching の本文（$j = 4$ で失敗し $j = \pi[3] = 2$、P を 2 文字ずらす。ここは幅と値が偶然同じ 2 なので、なおさら取り違えやすい）
- **直し方**：「$\pi$ は、照合に失敗したときに、ずらした後も一致が分かっている長さ（どこから比べ直すか）を表す」とする

### 5｜直すとよい｜fact（F2）｜#pitfalls の「添字の流儀を混ぜる」（238 行）

- **問題**：「`while` の条件を取り違えると無限ループか配列の外の参照になる」とあるが、$\pi[0] = 0$ の流儀で `j >= 0` にすると $j = 0$ で `pi[-1]` を読む（配列の外）。$A[0] = -1$ の流儀で `j > 0` にすると、$j = 0$ で不一致でもループを抜けて `j++` するので、無限ループではなく誤った値になる
- **根拠**：snuke の記事の形（`while (j >= 0 && S[i] != S[j]) j = A[j]; j++;`）で条件だけを `j > 0` にして追うと、$S = \texttt{ab}$ で $A[2] = 1$（正しくは 0）
- **直し方**：「配列の外の参照か、誤った値になる」にする

### 6｜直すとよい｜fact（F3）｜#linear-time の最後の段落（94 行）

- **問題**：「$S = \texttt{aaaa}\dots\texttt{ab}$ の最後の b では、$j$ が $N - 2, N - 3, \dots, 0$ と 1 ずつ減り、$N - 1$ 回たどる」の回数が 1 ずれる。`while` を回るのは $N - 2$ 回（比較は $N - 1$ 回）
- **根拠**：t.py で $N = 3, 5, 8$ のとき while の回数は 1・3・6
- **直し方**：「$N - 2$ 回たどる（比較は $N - 1$ 回）」か「$N - 1$ 個の状態を順に通る」にする
