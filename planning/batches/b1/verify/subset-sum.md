## 指摘

### 1｜直すべき｜分かりやすさ（U4）・事実（F2）｜#over-all-subsets の擬似コードと直後の段落

- **問題**：擬似コードは「各要素 a について（t は大きい方から）: dp[t] = 2 * dp[t] + dp[t - a]」とだけ書き、$t < a$（$t = 0$ を含む）でも 2 倍が要ることが書かれていない。ページのコード片 count.cpp の core は `for (int t = s; t >= a[i]; t--)` なので、読者がこれを下敷きにすると $t < a$ の 2 倍を落とし、答えが合わない
- **根拠**：$a = (1, 1)$、$S = 1$ で正しい答えは 4（$U$ が 1 つ目・2 つ目のそれぞれで $2^1$）。$t \ge a$ だけを更新すると 1 つ目の後 $\mathrm{dp}[0] = 1$ のまま（正しくは 2）になり、最後に $\mathrm{dp}[1] = 3$ となる。$t$ を $S$ から 0 まで回す版はランダムな 300 ケースで全探索と一致した
- **直し方**：擬似コードを「t = S, S-1, …, 0 について: dp[t] = 2 * dp[t] + (t >= a ? dp[t - a] : 0)」とし、本文に「和を変えない 2 通りは $t < a$ の和にもあるので、$t$ は 0 まで回して全部を 2 倍する」の 1 文を足す
