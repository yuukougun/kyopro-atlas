## 指摘

### 1｜直すべき｜手引き（§7、132 行）｜#wait の第 1 段落（76 行）

- **問題**：「このとき$a_e(t) = \mathrm{next}_e(t) + T_e$ になる」で、全角文字と数式の間に空白がない
- **根拠**：style-guide 132 行「半角英数字と全角文字の間に空白を入れる（「$O(N)$ で」）」。ほかの箇所はすべて空白がある
- **直し方**：「このとき $a_e(t) = \mathrm{next}_e(t) + T_e$ になる」にする

### 2｜直すとよい｜clarity（U3）｜#fifo の $a_e(t)$ の定義（48 行）と、待たない場合の説明（62 行）

- **問題**：$a_e(t)$ を「時刻 $t$ に始点にいるとき、終点に着ける最も早い時刻」と定義しているので、読者は待つことも含めた値だと読む。すると 2 つ目の条件（FIFO 性）は待てる限りいつも成り立つことになり、なぜ条件として挙げるのかが分からない。後の段落で「待たずにすぐ出るとき」と「$t$ 以降に出る中で最も早い到着時刻を $a_e(t)$ にすると」が出て、ようやく $a_e$ の中身が問題の決まり（待てるか）で変わることが分かる
- **根拠**：レート 1000 前後の読者として通読したときに、48 行と 62 行の $a_e$ の意味が一致しているかで止まった
- **直し方**：定義の直後に「待てない辺では、時刻 $t$ にすぐ出たときの到着時刻そのものである。待てる辺では、$t$ 以降のどの時刻に出るかも選べる」と一文足す

### 3｜直すとよい｜figure（G5）｜fifo.svg の $t \ge 2$ の部分

- **問題**：$t \ge 2$ では待たない場合と待てる場合の値が同じなので、赤い丸が青い四角の上に重なり、四角が見えない。凡例と本文（「実線と四角」）では四角が待てる場合の印なので、青い線の上に赤い丸だけが並ぶ形が一瞬分かりにくい
- **根拠**：full.png・narrow.png で、四角が見えるのは $t = 0, 1$ だけ
- **直し方**：本文の図の説明か代替テキストに「$t \ge 2$ では 2 つは同じ値で重なる」と一言足す。または丸を少し小さくし、四角を丸の上に描く

### 4｜直すとよい｜fact（F2）｜#pitfalls「時刻を状態に持ってしまう」（156 行）

- **問題**：「時刻を状態に持つのは、時刻の幅が小さく、FIFO 性が崩れる問題に限る」は言い過ぎ。FIFO 性があっても、時刻のほかに持つ量（使える回数・費用など）があって最も早い時刻だけでは足りない問題や、時刻を周期で割った余りを状態にする問題でも、時刻（または時刻の余り）を状態に入れる。執筆者も確認済みの例がないと報告している
- **根拠**：本文の #comparison でも「時刻の幅が小さく『時刻 $t$ にどこにいられるか』を全部持てるなら」と、FIFO 性が崩れない場合にも状態にする選択を書いており、156 行と食い違う
- **直し方**：「時刻を状態に持つのは、FIFO 性が崩れるか、時刻のほかの量と組で比べなければならず、しかも時刻の幅が小さい問題にする」程度に弱めるか、「〜に限る」を「〜のときだけ考えればよい」にする

### 5｜直すとよい｜clarity（U8）｜#fifo の確認問題「待てない場合」

- **問題**：問いは「時刻 0 に $u$ にいて」だけを与えるが、答えで初めて「別の経路で $u$ に時刻 2 に着いていれば」が出る。問いの 2 つ目（ダイクストラ法は正しい答えを出すか）は、$u$ に時刻 0 と時刻 2 の 2 通りで着ける設定がないと答えられない
- **根拠**：本文を理解した読者として問いだけを読むと、2 つ目に答える材料がない
- **直し方**：問いを「始点から $u$ へ、時刻 0 に着く経路と時刻 2 に着く経路があるとする。どこでも待てないとき、$w$ へ行けるか。各頂点で最も早い到着時刻だけを持つダイクストラ法は正しい答えを出すか」にする

### 6｜直すとよい｜clarity（U2）｜#optimal-departure「どちらも … を比べれば分かる」（138 行）

- **問題**：床関数の差と実数の差の比べ方が省かれていて、「$D/(x(x+1)) \ge 1$ なら床の差も 1 以上」が読者には飛躍になる
- **根拠**：$a - b \ge 1$ なら $\lfloor a \rfloor \ge \lfloor b + 1 \rfloor = \lfloor b \rfloor + 1$、$a - b \le 1$ なら $\lfloor a \rfloor \le \lfloor b \rfloor + 1$ の 1 段が要る（確かめ済み）
- **直し方**：「実数の差が 1 以上なら床の差も 1 以上、1 以下なら床の差も 1 以下になる。$h(x + 1) - h(x) = 1 - (\text{床の差})$ なので符号が決まる」と足す

### 7｜直すとよい｜fact（F2）｜#comparison の 3 つ目（164 行）

- **問題**：「便の時刻が周期的で、1 本の道を進むだけなら … 周期で割った余りごとに前計算」は、周期（の最小公倍数）が小さいときにしか使えない。ABC192 E のように周期が $10^9$ まであると余りごとの前計算はできない
- **根拠**：余りの数は周期の最小公倍数に比例する（例：補充の候補 abc319_e は周期 1〜8 で最小公倍数 840 だから成り立つ）
- **直し方**：「便の周期が小さく（最小公倍数が前計算できる大きさで）」と条件を足す
