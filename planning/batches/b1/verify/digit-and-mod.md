## 指摘

見出しは「番号. 重さ｜観点｜場所」の形。

### 1. 直すべき｜事実（F2・F3）｜divisibility の節 69 行「桁を並べ替える」

- 問題：「3 桁以下の 8 の倍数 $8, 16, \dots, 992$ のうち、数字の個数が足りるものがあるか」を試せば済む、とあるが、桁数が 3 以上のときは誤り。下 3 桁は必ず 3 つの数字を使うので、16 を「1 と 6 があれば作れる」と数えると、残りの 1 桁が 100 の位に来て値が変わる。反例：S = 116 は 1 と 6 を持つので「Yes」になるが、116・161・611 はどれも 8 の倍数でない
- 根拠：1〜9 だけの 3〜5 桁の数字列をすべて試すと、本文の判定と全探索（並べ替えをすべて試す）が 5933 件で食い違った（最初の例 116・118・124・138・142）。8 の倍数を 3 桁に 0 埋めした文字列（008, 016, …, 992）で数字の個数を比べると全件一致した。drken 氏の ABC181 D の記事も「8 は 008 と書くので 0 が 2 つ要る」と 0 埋めで扱っている。練習の方針（197 行の「3 桁の 8 の倍数（112 から 992 まで、0 を含むものを除く）」）は正しく、本文とだけ食い違う
- 直し方：「8 の倍数は下 3 桁だけで決まる。だから桁数が 3 以上なら、$0$ から $992$ までの 8 の倍数を 3 桁に 0 を補って（$008, 016, \dots, 992$）、その 3 つの数字が S の中に足りるものがあるかを試せば済む。桁数が 3 未満なら、その桁数で作れる数を全部試す」のように、0 埋めの 3 桁であることを明記する

### 2. 直すとよい｜コード（C3）｜snippets/digit-and-mod/substring-multiple.cpp 6 行のコメント

- 問題：「（p は素数）」とあるが、例題の解法の詳細（182 行）は同じ関数に $P = 2019$（素数でない）を渡してよいと書いている。関数の正しい範囲は「p が 2・5 か、10 と互いに素」で、p = 4・6 などでは誤る
- 根拠：本文 182 行とコメントの食い違い。p = 4 は接尾辞の分岐に入り、S = "20" で 3 を返すが、全探索では 2（「2」は 4 の倍数でない。10 と 4 が互いに素でないため）
- 直し方：コメントを「（p は 2・5 か、10 と互いに素な数）」にする

### 3. 直すとよい｜事実（F1）｜p-2-5 の節 150 行「$O(N + Q)$ で数えられる」

- 問題：右端 $r$ ごとに「最後の $k$ 桁が $2^a 5^b$ の倍数か」を調べる手間が入っていない。素直に $k$ 桁を読むと $O(Nk)$ で、長さ $k$ 未満を直接調べる分も $O(Nk)$（値の計算を含めると $O(Nk^2)$ にもなりうる）。全体の計算量が書かれていない
- 根拠：手順の数え直し。$k \le \log_2 P$ なので実用上は小さいが、「$O(N + Q)$」だけを読むと全体がそうだと受け取れる
- 直し方：「全体で $O(Nk + Q)$（$k \le \log_2 P$ なので小さい）」と書く

### 4. 直すとよい｜分かりやすさ（U3）｜concatenation の節 88 行「$y$ が掛かるのは $10^{d(y)}$ の形だけなので」

- 問題：$y$ は $+y$ としても式に現れるので、「$y$ が掛かるのは」が何を指すか一度で読めない。言いたいのは「$x$ に掛かる係数のうち $y$ で決まるのは $10^{d(y)}$ だけ」ということ
- 根拠：clarity U3
- 直し方：「$x$ に掛かる $10^{d(y)}$ は $y$ の桁数だけで決まるので、$y$ の桁数 $d$ を固定すると $10^d$ は定数になる」とする

### 5. 直すとよい｜分かりやすさ（U4）｜pitfalls の節 158 行「答えと $\mathrm{cnt}$ の掛け算は `long long` で行う」

- 問題：本文の手順とコードには掛け算がない（cnt を足していくだけ）。$\binom{c_u}{2} = c_u(c_u - 1)/2$ で数える書き方のことだと分かりにくい
- 根拠：snippet の core と本文 121〜123 行の手順
- 直し方：「答えは `long long` で持つ。余りごとの個数から $c_u(c_u - 1)/2$ で数えるなら、この掛け算も `long long` で行う」とする
