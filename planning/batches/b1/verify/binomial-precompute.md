## 指摘

### 1. 直すべき｜F2・U8｜#composite-mod の確認問題「前計算が使えない理由」の答え

- **問題**：「$k \ge 5$ なら $k!$ は 2 と 5 を両方含み、法と互いに素でなくなる」と書いている。互いに素でなくなるには素因数を 1 つ共有すれば足り、$k \ge 2$ で $k!$ は 2 を含むので、$k = 2$ の時点で逆元は存在しない（$2! = 2$ と $10^9$ は互いに素でない）。今の書き方では「$k \le 4$ なら表が使える」「2 と 5 の両方が要る」と読めてしまい、互いに素の条件を誤って覚えさせる
- **根拠**：$\gcd(2, 10^9) = 2 \ne 1$。ACL の `inv()` の要件は gcd(x.val(), mod) = 1（document_ja/modint.md）
- **直し方**：「$10^9 = 2^9 \cdot 5^9$ なので、$k \ge 2$ なら $k!$ は 2 を含み、法と互いに素でなくなる。逆元が存在しないので $\mathrm{ifact}[k]$ を作れない（$k \ge 5$ なら 5 も含む）」のように、1 つの素因数の共有で十分であることを書く

### 2. 直すとよい｜U3・F7｜練習の方針（#practice の折りたたみ）の AGC043 B

- **問題**：「[答えの偶奇](#parity-pyramid)は $\binom{n}{i} \bmod 2$ を係数にした和で決まる」の $n$ が定義されていない。本文の節では長さ $N$ の列に $\binom{N-1}{i}$ を使い、方針の後半では「最初に 1 回差を取って 0・1・2 の列にし」とあるので、差を取った後なら $\binom{N-2}{i}$ になる。どちらの列の話かが分からない。また文の順序が「偶奇の式 → 最初に差を取る」で、手順の順と逆になっている
- **根拠**：本文 #parity-pyramid の式 $\sum \binom{N-1}{i} a_i$。差を取った列の長さは $N-1$
- **直し方**：「最初に 1 回差を取って 0・1・2 の長さ $N-1$ の列にする。最後の値の偶奇は $\binom{N-2}{i} \bmod 2$ を係数にした和で決まる（元の列で $\binom{N-1}{i}$ を使ってもよい）。1 を含むかどうかで場合分けする」のように、記号を本文にそろえ、手順の順に並べる

### 3. 直すとよい｜F2・U3｜#table-size の表「$K$ 個の区別のない玉を $N$ 個の箱へ」

- **問題**：$\binom{N+K-1}{K}$ は空の箱を許すときの数で、各箱に 1 個以上なら $\binom{K-1}{N-1}$ になる。条件が書かれていない
- **根拠**：重複組合せの標準的な結果（[重複組合せ](../comb/stars-and-bars.md) のページの主題）
- **直し方**：「$K$ 個の区別のない玉を $N$ 個の箱へ（空の箱を許す）」とする

### 4. 直すとよい｜F2｜#examples の鉄則本 A30「$n < p$ なので分母は 0 にならない」

- **問題**：執筆者の未解決の点のとおり、A30 の制約は第三者の資料で確かめられていない。本文は制約に触れないまま「$n < p$」を前提にしている
- **根拠**：evidence の解答コード（E869120/kyopro-tessoku answer_A30.cpp）は `for (int i = 1; i <= n; i++)` で O(n) の階乗を作っており、n が p（10^9+7）より十分小さいことは読み取れるが、上限の値は書かれていない
- **直し方**：今の書き方で事実に反するわけではないので必須ではない。「$n$ までのループが回る大きさなので $n < p$ で、分母は 0 にならない」と根拠を添えるか、制約が確かめられたら上限を書く

### 6. 直すとよい｜U4｜#composite-mod の「32 bit で持つか」

- **問題**：パスカルの三角形を 32 bit（int）で持つと、足し算 `C[i-1][j-1] + C[i-1][j]` は最大 $2(M-1)$ になり、$M > 2^{30}$ 程度で int があふれる。メモリを減らす方法として 32 bit を勧めるなら、条件が要る。コード片は long long の正方形の表で、本文の勧めと形が違う（これ自体は本文の 200 MB の見積もりと一致しているので問題ない）
- **根拠**：$2 \times (10^9 + 6) \approx 2.0 \times 10^9 < 2^{31}$ なので $M \le 10^9$ 程度なら int で足りるが、$M$ が $2^{30}$ を大きく超えると足りない
- **直し方**：「法が $10^9$ 程度までなら 32 bit（足してから mod を取る間は 64 bit）で持つか」のように条件を添える
