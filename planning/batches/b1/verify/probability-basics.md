## 指摘

### 1. 直すべき｜事実（F2）｜#pitfalls「積の期待値を期待値の積にする」

- 問題：「$E[XY] = E[X] \, E[Y]$ は $X$ と $Y$ が独立なときだけ成り立つ」は言い過ぎ。独立は十分条件で、必要条件ではない（無相関なら成り立つ）
- 根拠（反例）：$X$ を $\{-1, 0, 1\}$ から等確率、$Y = X^2$ とすると、$X$ と $Y$ は独立でない（$X = 0$ なら $Y = 0$ に決まる）が、$E[XY] = E[X^3] = 0 = E[X] \, E[Y]$
- 直し方：「$X$ と $Y$ が独立なら成り立つが、一般には成り立たない」とする

### 2. 直すとよい｜分かりやすさ（U3・U8 寄り）｜#pitfalls「条件付き確率の向きを取り違える」

- 問題：$P(A \mid B)$ と $P(B \mid A)$ が違うことを示す段落なのに、例が両方 $1/6$ で等しくなる場合で、違いが見えない。読者は「結局同じでは」と受け取りうる
- 根拠：同じ表で、$P(\text{和が } 12 \mid \text{1 回目が } 6) = 1/6$ だが $P(\text{1 回目が } 6 \mid \text{和が } 12) = 1$。または $P(\text{和が } 7 \mid \text{少なくとも一方が } 3) = 2/11$ に対し $P(\text{少なくとも一方が } 3 \mid \text{和が } 7) = 2/6 = 1/3$（確認問題の値を再利用できる）
- 直し方：値が違う例を先に置き、「1 回目が 3 / 和が 7」の一致は「たまたま」の補足に回す

### 3. 直すとよい｜事実（F2）・分かりやすさ（U3）｜#expectation 全期待値の公式

- 問題：「排反な $B_1, \dots, B_m$ について $E[X] = \sum_i P(B_i) \, E[X \mid B_i]$」で、「どれか 1 つが必ず起きる（全体を覆う）」の条件が書かれていない。全確率の公式の節では書いてあるが、この節を断片で読むと条件が欠ける（U6）
- 根拠：全体を覆わない分け方（例：サイコロで $B_1 = \{1\}, B_2 = \{2\}$ だけ）では右辺が $E[X]$ にならない
- 直し方：「排反で、どれか 1 つが必ず起きる $B_1, \dots, B_m$ について」とする

### 4. 直すとよい｜分かりやすさ（U3）｜#next-steps「後ろ向き（期待値 DP）」

- 問題：漸化式 $f(s) = c(s) + \sum_t P(s \to t) \, f(t)$ の $c(s)$ が定義されていない
- 根拠：本文に $c$ の説明がない。確率を求める場合（$c(s) = 0$）と回数の期待値（$c(s) = 1$）の違いが読み取れない
- 直し方：「$c(s)$ は 1 手で加わる量（回数の期待値なら 1、確率なら 0）」と添える
