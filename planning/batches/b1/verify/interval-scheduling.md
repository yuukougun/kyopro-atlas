## 指摘

### 1｜直すとよい｜事実（F2）・分かりやすさ（U3）｜#stabbing「最大個数と最少の点の数は一致する」の段落

- **問題**：「区間スケジューリングの貪欲で選んだ $k$ 個の区間の右端（整数の半開区間なら右端の直前 $r - 1$）に点を置く」は、ページが決めた半開区間の貪欲（$l \ge \mathrm{last}$）で選んだ区間について「右端に点を置く」が基本形に読める。実数の半開区間 $[l, r)$ では $r$ は区間の外なので、そのままでは成り立たない。閉区間なら貪欲の条件が $l > \mathrm{last}$ に変わる（確認問題のとおり）ことにも触れておらず、どの区間の表し方の話かが段落の中で揺れている。また最後の「上の図の網かけの列がその点である」は別の節（#why-right-end）の図を指しており、節だけを取り出すと通じない（U6）
- **根拠**：半開区間 $[0, 3)$ に点 3 は入らない。強双対の議論は「飛ばした区間は $l < \mathrm{last}$ かつ右端 $\ge \mathrm{last}$」から点 $\mathrm{last} - 1$（整数）を含む、で成り立つ。全探索との突き合わせでは整数の半開区間で $r - 1$ に置いて一致
- **直し方**：「閉区間なら貪欲（条件 $l > \mathrm{last}$）で選んだ区間の右端に、整数の半開区間なら右端の直前 $r - 1$ に点を置く」と、表し方ごとに条件と点の位置を対にして書く。図への言及は「[右端の順に選ぶ理由](#why-right-end)の図の網かけの列」とする

### 2｜直すとよい｜分かりやすさ（U2）｜#why-right-end「なぜ正しいか」の 2 段落目

- **問題**：「$O$ のほかの区間はどれも $o$ の右端以降から始まり」の理由がない。読者は「$o$ より左にある区間はないのか」で止まる
- **根拠**：$O$ の区間は互いに重ならず、$o$ は右端が最小なので、ほかの区間が $o$ より左に収まると右端が $o$ の右端より小さくなって矛盾する。だから $o$ の右端以降から始まる
- **直し方**：「$O$ の区間は互いに重ならず、$o$ の右端が最小なので、ほかの区間はどれも $o$ の右端以降から始まる」と理由を 1 句足す

### 3｜直すとよい｜分かりやすさ（U3・U4）｜#deadlines の 3 つ目の項目

- **問題**：「各仕事が開始可能な時刻と締め切りを持ち、1 単位時間に 1 個処理する」は、何を求める問題か（できるだけ多くの仕事を締め切りまでに処理する、またはすべて処理できるか）が書かれていない。締め切りを過ぎた仕事をキューから捨てる処理もなく、手順だけでは実装で迷う
- **根拠**：締め切りの最も早いものから処理する方法（EDF）は、処理時間が 1 の仕事で「締め切りまでに処理できる数の最大」や「すべて処理できるか」に正しいが、取り出した仕事が締め切りを過ぎていれば捨てる必要がある
- **直し方**：「処理時間が 1 の仕事を、締め切りまでにできるだけ多く処理する：…締め切りの最も早いものから処理する（締め切りを過ぎたものは捨てる）」とする

### 6｜直すとよい｜分かりやすさ（U7）｜練習の方針の ARC106 C

- **問題**：構築の説明は $M \ge 1$（と $N \ge 2$ の $M = 0$）のときにしか使えない。$N = 1$・$M = 0$ は「長い区間 1 本と短い区間 $M + 1$ 個」が置けないが答えはあり、「$M$ が大きすぎるときに作れない」と考えた読者が $M \ge N - 1$ をすべて不可にして誤る
- **根拠**：drken の ARC106 C の記事は $M = 0$ を先に場合分けし（重ならない区間を $N$ 個並べる）、$N = 1$・$M = 0$ を例外として扱っている
- **直し方**：「$M = 0$ は重ならない区間を $N$ 個並べるだけなので、先に分けておく」と 1 文足す

## 確かめて問題がなかった点（抜粋）

- 計算量：要点・front matter の complexity・本文で $O(N \log N)$（ソートが支配的、走査 $O(N)$）が一致。重み付きは二分探索で $O(N \log N)$ と書かれ、コードと一致（F1）
- 右端が同じ区間の順を問わない理由、左端の大きい順も正しい理由、閉区間の確認問題（$l > \mathrm{last}$、または $[l, r + 1)$ に直す）、last の番兵の落とし穴、`pair` の既定の比較の落とし穴：いずれも正しい（F2）
- 幅 $D$ の範囲で突く場合の「$x = r$ に寄せてよい」：残りの区間はどれも右端が $r$ 以上なので、$[x, x + D - 1]$ が当たる条件は $l_j \le x + D - 1$ だけになり、$x$ について単調。本文と例題の解法の詳細の説明は正しい
- ABC230 D の解法の詳細：前のパンチの範囲 $[e - D + 1, e]$ の左端は前の壁の右端で $R_i$ 以下、なので $L_i \le e$ だけで判定できる、は正しい。evidence の方針と一致
- ABC103 D の確認問題（要望 $(a, b)$ は橋の閉区間 $[a, b - 1]$）：evidence の記事が半開区間 $[a, b)$ と抽象化しているのと同じ内容
- 重み付き DP：`upper_bound(rs.begin(), rs.begin() + i, l)` は先頭 $i$ 個のうち右端 $\le l$ の個数で、添字 $i$ 以降に右端 $\le l_i$ の区間はない（右端の順なので）。本文の状態・遷移とコードが一致（C3）
- コード片：取り込みは core の関数だけ、比較はラムダ、`'\n'`、マクロ・型の別名なし（C4・C5）。座標・重みは long long（C8）
- 図：値・ラベル・点の位置は本文・代替テキストと一致。背景は白で塗られ、選んだ区間は実線と太字、飛ばした区間は破線と「×」で、色だけに頼っていない（G4・G5）。catalog の visual は priority 3 なので静的な図で代えてよい（G7）
