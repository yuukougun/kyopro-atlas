### 2｜直すとよい｜事実（F2）｜#count-by-color の表の 3 行目と、その後の「引く $M$ と重ならない」

- **問題**：式 $\binom{N}{2} - M - \sum_i (\binom{a_i}{2} + \binom{b_i}{2})$ は、$M$ が「辺で結ばれた頂点の組の数」に等しい単純グラフでしか成り立たない。ページは #coloring・#pitfalls で多重辺を許す扱いをしているので、読者がそのまま一般のグラフに使うと誤る
- **根拠**：t.py。N = 2、辺 0–1 を 2 本のとき、式は $1 - 2 - 0 = -1$、正しくは 0。単純グラフのランダムな例ではすべて一致
- **直し方**：表の行か直後の文に「多重辺がない（単純グラフの）とき。多重辺があれば $M$ を辺で結ばれた組の数に置き換える」と 1 文足す（ABC282 D は単純グラフなので練習の方針はそのままでよい）

### 3｜直すとよい｜事実（F2）・記法（F7）｜#challenge の力試しの方針（3 Steps）

- **問題**：「長さが奇数の道」「どの 2 頂点の間にも奇数長の道があり」の「道」が、graph-basics の用語（#terms） の「パス（頂点を繰り返さない）」と読めると誤りになる。奇閉路があっても、2 頂点の間に奇数長のパスがあるとは限らない（例：パス x–z–y の z に、橋を介して三角形がぶら下がるグラフで、x–y のパスは長さ 2 の 1 本だけ）。「閉路を回って偶奇を変える」のはウォークの話である
- **根拠**：上の反例。kmjp 氏の記事も「奇数距離で移動できる」で、頂点の繰り返しを許す意味で書いている
- **直し方**：「長さが奇数のウォーク（頂点の繰り返しを許す道）」と書き、2 か所をそろえる

### 4｜直すとよい｜分かりやすさ（U2）｜#union-find、「それまで矛盾がなければ、足した辺の端点 $u$ だけを調べれば足りる」の段落

- **問題**：「矛盾が生じるのは $u$ と $v$ がすでに同じグループのときだけ」と言い切るが、示しているのは「同じグループなら矛盾する」向きだけで、「それ以外では矛盾が生じない」理由がない。読者は端点以外の $x$ で $x$ と $x + N$ がつながる心配を消せない
- **根拠**：手計算（上の「手計算」の項）。主張自体は正しく、dsu-double.cpp の assert とランダムな試しでも確かめた
- **直し方**：「$u$ を含むグループを $A$、$v$ を含むグループを $B$、それぞれの『色を入れ替えた』グループを $A'$・$B'$ とすると、併合でできるのは $A \cup B'$ と $A' \cup B$ だけである。$A \ne B$ なら、$x$ と $x + N$ はいつも片方ずつに分かれる」のように 1〜2 文足す

### 5｜直すとよい｜コード（C3）｜#coloring の手順 2 と coloring.cpp の取り込み

- **問題**：本文は $\mathrm{color}[v] = 1 - \mathrm{color}[u]$、コードは `color[u] ^ 1` で、同じ処理が別の式で書かれている。C++ に不慣れな読者は `^` を累乗と取り違えうる
- **根拠**：coloring.cpp の `color[v] = color[u] ^ 1;  // 隣は反対の色`
- **直し方**：コードを `1 - color[u]` にそろえる（cases の出力は変わらない）か、本文に「（コードでは XOR で `color[u] ^ 1`）」と添える
