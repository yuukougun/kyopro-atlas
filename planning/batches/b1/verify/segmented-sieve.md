## 指摘

### 1｜直すべき｜事実（F2）｜#why-sqrt の 70 行（s の求め方の段落）と #pitfalls の「√R の誤差」（139 行）

- **問題**：「$R$ が $2^{53}$ を超えると $R$ を `double` に直す時点で丸めが起き、$s$ が 1 小さくなることがある。$R$ がちょうど素数 $p$ の 2 乗のときにそうなると、$p$ を使い損ねて $R$ を素数と誤判定する」は、long long の範囲では起きない。`double` の `sqrt` のずれは逆向き（1 大きくなる）で、しかも $2^{53}$ より前の約 $4.5 \times 10^{15}$ から起きる。前提に挙げた[整数の平方根](../math/integer-root.md)の 52 行（「$4.5 \times 10^{15}$ ほどの大きさで、もう 1 大きい値を返すことがある」）とも食い違っている
- **根拠**：g++-15 -O2 で `(long long)sqrt((double)(p*p)) < p` となる $p$ を、$1 \le p \le 3037000499$（$p^2 < 2^{63}$）の全部で数えた：0 個。`(long long)sqrt((double)(p*p - 1)) >= p`（1 大きくなる）の最小は $p = 67108865$、$R = 4503599761588224 \approx 4.5 \times 10^{15} < 2^{53}$。理屈でも、$R$ を `double` に丸める操作は単調なので丸めた値は $s^2$ を丸めた値以上で、その平方根は相対誤差 $2^{-54}$ 以内で $s$ に近く、正しく丸められた `sqrt` は $s$ を返す（$s < 2^{32}$ は `double` で正確に表せる）。なお区間篩では $s$ が 1 大きくても余分な素数で篩うだけで結果は変わらない（本文の「余裕を持たせる」の説明のとおり）
- **直し方**：たとえば 70 行を「`double` の `sqrt` は、$R$ が $4.5 \times 10^{15}$ ほどを超えると 1 大きい値を返すことがある（[整数の平方根](../math/integer-root.md)）。区間篩では余分な素数で篩うだけで害はないが、$s$ をほかの用途（素数の個数の見積もり・配列の大きさ）にも使うなら、整数で $(s+1)^2 \le R$・$s^2 \le R$ を確かめて求めておく」とし、「素数の 2 乗を素数と誤判定する」の筋は消す。139 行の落とし穴も同じ向きに直す（「1 小さくなる」→「1 ずれる（大きくなる）ことがあり、ほかの環境・型では小さくなることもありうるので、整数で確かめる」程度）。「$R \le 10^{12}$ なら `double` の `sqrt` でもずれない」は正しいので残してよい

### 2｜直すとよい｜事実（F3）｜#factorize-range の 110 行（数ごとの vector のメモリ）

- **問題**：「数ごとに `vector` を持つと、$10^6$ 個で数十 MB になることがある」は控えめすぎる。実測では 100 MB を超える
- **根拠**：factorize.cpp を `999999000000 1000000000000`（10^6 + 1 個）で動かし、`/usr/bin/time` の最大 RSS が 128 MB（rem の 8 MB を除いても 100 MB 余り）。空の `vector` 自体が 24 バイトで、各数に要素を確保する分のヒープの管理領域が乗る
- **直し方**：「$10^6$ 個で 100 MB を超えることがある」に直す

### 3｜直すとよい｜事実（F2）・分かりやすさ（U3）｜#first-multiple の 82 行

- **問題**：「$p^2$ 未満の $p$ の倍数 $kp$（$k < p$）は $k$ の素因数でもう消えている」は $k = 1$（$p$ 自身）を含んでしまう。$k = 1$ には素因数がなく、まさにその $p$ を消さないための話なので、条件がずれて読める
- **根拠**：$k = 1$ のとき $kp = p$ は素数で、消してはいけない数である
- **直し方**：「$kp$（$2 \le k < p$）」とする

### 4｜直すとよい｜分かりやすさ（U3・U9）｜#why-sqrt の 52 行の括弧

- **問題**：「$\sqrt{R}$ 以下のどの素数の倍数にもならない区間の数（ただし 2 以上で、それ自身ではない倍数として消す。次の節）は素数である」の括弧が読み取りにくい。「どの素数の倍数にもならない」と言いながら、素数 $p$ 自身は $p$ の倍数なので、読者は「$[2, 30]$ の 2 は 2 の倍数だから素数でない？」とつまずく
- **直し方**：「区間の 2 以上の数のうち、$\sqrt{R}$ 以下のどの素数 $p$ についても『$p$ 自身でない $p$ の倍数』にならないものは素数である。$p$ 自身と 1 の扱いは次の節で述べる」のように括弧をほどく
