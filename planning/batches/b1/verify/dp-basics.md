## 指摘

### 1. 直すべき｜事実（F8 出典に近すぎる）｜four-parts の例・図・動く図の config・frog.yaml の 3 つ目のケース

- **問題**：足場の例の高さ (2, 9, 4, 5, 1, 6) は、参考に挙げた drken の EDPC 記事が Frog 1 の説明に使う例 h = (2, 9, 4, 5, 1, 6, 10) の最後の 1 つを落としたものである。表の途中の値（足場 1 が 7、足場 2 が 2、足場 3 が 3）も記事の図と同じになる。執筆者の報告にはこの一致が書かれていない
- **根拠**：WebFetch で記事を読み、「N = 7、h = (2, 9, 4, 5, 1, 6, 10)、途中経過として足場 2 が 7、足場 3 が 2、足場 4 が 3（1-indexed）」を確かめた。fact.md F8 の「よくある失敗」は、記事の例を同じ数値のまま使うことを挙げている
- **直し方**：自分で作った高さの列に替える（たとえば長さ 6 で、同じ足場に 2 通りでたどり着き、1 つ先と 2 つ先の比べ方が途中で入れ替わるもの）。替える場所は本文の four-parts（l.59・l.72）、動く図の `data-config`、push-pull.svg とその代替テキスト、frog.yaml の 3 つ目のケース、報告の動く図の仕様（20 回の呼び出しの数も数え直す）

### 2. 直すとよい｜図（G5・G3）｜push-pull.svg のラベルと矢印の重なり

- **問題**：座標から計算すると、ラベルが別の矢印の曲線にかかる

  - 「+|1−4| = +3」（y=214）と下の段の見出し（y=228、文字の上端 y≈215）の間がほぼない
- **根拠**：2 次ベジェ曲線の式で、各ラベルの x の位置での曲線の y を求めた（目では見ていない。描画の道具が手元になかった）

### 3. 直すとよい｜図（G5）・分かりやすさ（U3）｜push-pull.svg の下の段の値

- **問題**：配る形の段は「dp[2] を配る瞬間」を描いているのに、dp[3]・dp[4] のマスに最終の値（3・5）が入っている。その瞬間の dp[3] は dp[1] から来た 11、dp[4] はまだ INF なので、「min(dp[3], 2 + 1)」で 3 になる流れが図から読めない
- **根拠**：表を昇順に配って追った（dp[1]=7 から dp[3] へ 7+4=11）
- **直し方**：下の段の dp[3]・dp[4] を「11 → 3」「∞ → 5」のように更新前後で書くか、マスを空にして右の式だけで示す

### 4. 直すとよい｜分かりやすさ（U4）・事実（F2）｜pull-to-prefix-sum の式の範囲

- **問題**：本文の式 $S_{i-L+1} - S_{\max(0, i-R)}$ は、$i < L$ のとき添字 $i - L + 1$ が 0 以下になり、そのままでは意味を持たない（コードは `lo < hi` で除いている）。また $L \ge 1$ の条件が本文にない（$L = 0$ だと自分自身が遷移元になり、昇順で回せない）
- **根拠**：range-pull.cpp l.20〜21 と本文 l.147 の比較。`4 5 9` のケースはこの場合分けで 0 になる
- **直し方**：「$1 \le L \le R$ とする」と「$i < L$ なら遷移元がなく $\mathrm{dp}[i] = 0$」を 1 文ずつ足す

### 5. 直すとよい｜事実（F7 記法）｜pull-to-prefix-sum の配る形（l.153）

- **問題**：「区間 $[i + L, i + R]$」が閉区間なのに「閉区間」と書いていない（直前の l.147 は「閉区間 $[i - R, i - L]$」と明記している）。手引き §6 は閉区間を明記する決まり
- **直し方**：「閉区間 $[i + L, i + R]$（$N - 1$ を超える分は捨てる）」にする。いもす法と合わせるなら「半開区間 $[i + L, i + R + 1)$」でもよい

### 6. 直すとよい｜分かりやすさ（U3）｜three-kinds の表の「答えの例」

- **問題**：ページの冒頭で「足場 $0, \dots, N-1$」「答えは $\mathrm{dp}[N-1]$」と決めた直後に、表の答えが $\mathrm{dp}[N]$ になっている。$\mathrm{dp}[N]$ が「先頭 $N$ 個を見た後」の意味だという説明は落とし穴の節（l.194）まで出てこないので、読者は添字がずれたように見える
- **直し方**：表の前か後に「ここでの $\mathrm{dp}[N]$ は先頭 $N$ 個を見た後の状態（[添字のずれ](#pitfalls)）」と 1 文足すか、列名を「答えの例（先頭 $N$ 個を見た後を $\mathrm{dp}[N]$ とする）」にする

### 7. 直すとよい｜事実（F2）｜three-kinds l.93「単位元を遷移でまとめても結果は変わらない」

- **問題**：最小化では、到達できない状態の値 $+\infty$ そのものではなく $+\infty + \text{コスト}$ がまとめられる。これが「変わらない」のは INF が十分大きく、足してもあふれないときだけで、落とし穴の節の INF のあふれと同じ条件である。今の書き方は無条件に読める
- **直し方**：「（INF にコストを足しても INF より小さくならない大きさにしておけば）」の一言を足し、落とし穴の節へリンクする
