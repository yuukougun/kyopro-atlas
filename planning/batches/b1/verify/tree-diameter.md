## 指摘

### 1. 直すべき｜事実（F2）｜#negative-weights、本文 144 行

- **問題**：「$v$ を最も浅い頂点とするパスの最大は、$\mathrm{up}[c] + w_c$ の上位 2 つ（足りなければ 0）の和」と書いているが、負の重みがあると $\mathrm{up}[c] + w_c$ 自体が負になる。そのまま上位 2 つを足すと、片側だけに伸ばすパス（や 1 頂点）より小さい値になり、そのパスはほかのどの頂点でも数えられないので、答えが小さくなる。この節はまさに負の重みのための節なので、ここで誤ると目的を果たさない
- **根拠**：根 0 に子 1（重み 10）と子 2（重み $-100$）。直径は 0–1 の 10。書かれたとおりだと頂点 0 で $10 + (-100) = -90$、葉で 0 なので答えは 0。ランダムな木（$N \le 7$、重み $-5$〜$5$）3000 個のうち約 480 個で全点対の最大と不一致。各候補を $\max(0, \cdot)$ にしてから上位 2 つを取ると 3000 個すべてで一致
- **直し方**：「$\max(0, \mathrm{up}[c] + w_c)$ の上位 2 つ（足りなければ 0）の和」とする。あるいは「候補 $\mathrm{up}[c] + w_c$ のうち正のものだけの上位 2 つ」と書く。直後の「max の中の 0 は…」の文もこの 2 か所を指すように直す

### 2. 直すべき｜事実（F9）｜#long-path-decomposition の折りたたみ「貪欲が正しい理由の筋」、本文 221 行

- **問題**：最後の「詳しくは参考の解説にある」は事実と違う。参考の drken の記事は「ちゃんとした証明を書くのは面倒」と断って概略だけを書き、K=3 以降は「同様」で済ませている。執筆者も未解決の点に「drken の記事でも詳細は省かれている」と書いている
- **根拠**：https://drken1215.hatenablog.com/entry/2024/09/03/035714 の該当部分
- **直し方**：その文を消すか、「参考の解説も概略だけを示している」に変える。交換の筋そのものは検証した（分かれる点が最も深い葉 $u$ を $v_1$ に替えると、失うのは高々 $d(z,u)$、得るのは $d(z,v_1) \ge d(z,u)$）。厳密にするなら「失う辺は $z$ より下の $u$ 側だけで、その長さは $d(z,u)$ 以下。$z$ より下の $v_1$ 側の辺はどの選んだ葉にも覆われていないので、$d(z,v_1)$ だけ増える」を 1 文足すとよい

### 3. 直すとよい｜分かりやすさ（U3）・事実（F2）｜#double-sweep、本文 79・85 行

- **問題**：79 行の「重みが非負なので $d(s,u) \le d(s,x)+d(x,y)+d(y,u)$」は、$x \ne y$ のときは重みによらず等式である。非負が要るのは $x = y$ のときだけで、それは折りたたみにある。また 85 行の「この不等式が等号になるには $d(y,a)=d(y,q)$ が要る」は $x \ne y$ の場合の議論である。$x = y$（$a$ が $s$ と同じ枝）のときに $a$ が直径の端点になる理由（$d(s,x)+d(x,q) = d(s,a) \le d(s,x)+d(x,a)$ と枝の深さの性質から $d(x,a)=d(x,q)$）は折りたたみにも書かれていない
- **根拠**：上の式の展開。主張自体は検証プログラムで正しいと確かめた
- **直し方**：79 行は「$x \ne y$ なら $s$ から $u$ へのパスは $x$・$y$ を通るので」とする。折りたたみの $x = y$ の項に、等号の場合も同じく $d(x,a) = d(x,q)$ が出て $d(p,a) = D$ になることを 1 文足す

### 4. 直すとよい｜分かりやすさ（U2・U3）｜#center、本文 189 行

- **問題**：「すべての直径は中心を通り、中心がその真ん中になる」の根拠として挙がっているのは「2 本の直径は共通の頂点を持つ」ことだけで、主張（中心を通る・真ん中になる）を示していない。確認問題の答え（205 行）も「どの直径も中心を通るから」と、示していない主張に頼っている
- **根拠**：共通の頂点を持つことから、中心を通ることは出ない
- **直し方**：「どの直径についても、その真ん中の頂点（または辺）から全頂点への距離は、枝の深さの性質（[2 回の探索の節](#double-sweep)）から $\lceil D/2 \rceil$ 以下になる。だから直径の真ん中は中心であり、中心は 1 頂点か隣り合う 2 頂点しかないので、すべての直径の真ん中は同じ中心である」と書く。2 本が交わる話はその例として残してもよい

### 5. 直すとよい｜分かりやすさ（U3）｜#abc428_e の解法の詳細 3 つ目、本文 256 行

- **問題**：「中心から距離が半径の頂点」は、$D$ が奇数（中心が 2 頂点）のとき、どちらの中心から測るのかがあいまいである。正しくは、$v$ と反対側の中心から距離 $(D-1)/2$ の頂点（$v$ 側の中心からは距離が半径 $(D+1)/2$）
- **根拠**：検証プログラムで答えの選び方は正しいと確かめた。表現だけの問題
- **直し方**：「直径の端点になれる頂点（偶数なら中心から距離 $D/2$、奇数なら真ん中の辺の各側でその側の中心から距離 $(D-1)/2$）のうち、$v$ を含まない枝（または側）にあるもの」と、節 center の 191 行の言い方にそろえる

### 6. 直すとよい｜事実（F2）｜#pitfalls「直径の頂点列を 1 回目の探索の親でたどる」、本文 235 行

- **問題**：「1 回目の親をたどっても $a$–$b$ のパスにならない」は言い過ぎで、$s$ が $a$–$b$ のパスの上にあれば偶然なる
- **直し方**：「$a$–$b$ のパスになるとは限らない」
