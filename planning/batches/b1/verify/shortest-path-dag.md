## 指摘

### 1｜直すべき｜fact（F2）｜#build の最後の段落（72 行）と #shortest-path-tree（110・112 行）

- **問題**：72 行「最短路木を作るだけなら、重み 0 の辺があっても困らない。各頂点に入る辺を 1 本選ぶだけで、閉路は生じない」は誤り。重み 0 の辺があると、きつい辺を頂点ごとに勝手に 1 本選ぶと閉路ができる。同じ理由で、112 行の「距離が等しい辺が見つかっても付け替えない。どちらの辺を選んでも最短路木になるからである」の理由づけも重み 0 では成り立たない（付け替えないのは、閉路を作らないためでもある）。110 行の「選んだ辺はどれも $s$ の側から伸びるので…閉路がなく」も、重みが正（親の距離が真に小さい）ことに頼っていると書かれていない
- **根拠**：反例 s-a（1）・s-b（1）・a-b（0）。距離は a = b = 1 で、a→b と b→a がどちらもきつい。a の親に b、b の親に a を選ぶと閉路になり s とつながらない。ダイクストラ法で等しいときも付け替える版を書くと、実際に par[a] = b・par[b] = a になった（v-shortest-path-dag/eq.cpp）。一方、スニペットどおり真に短くなったときだけ記録すれば、重み 0 を含む 2000 個のグラフで常に正しい木になった（spt_check.py）
- **直し方**：72 行を「最短路木は、ダイクストラ法で距離が真に短くなったときだけ親を記録すれば、重み 0 の辺があっても作れる（[最短路木の節](#shortest-path-tree)）。きつい辺を頂点ごとに勝手に 1 本選ぶと、0 の辺の両向きを選んで閉路になることがある」とする。110 行に「重みが正なら、選んだ辺の始点は距離が真に小さいので閉路がない」と条件と理由を書き、112 行の「どちらの辺を選んでも最短路木になるからである」は「重みが正ならどちらでもよいが、重み 0 の辺があると、等しいときに付け替えて閉路ができることがある」とする

### 2｜直すべき｜fact（F2）・clarity（U3）｜#edge-on-path の「s からのきつい辺だけでは足りない」（136 行）

- **問題**：「$s$-$t$ 最短路の本数や辺を問われたら、$\mathrm{dt}$ も求めて上の等式で絞る」の「本数」は誤り。$s$-$t$ 最短路の本数は $s$ からの DAG だけで求めた $\mathrm{cnt}[t]$ で正しく数えられる（$t$ に続かない枝は $\mathrm{cnt}[t]$ に足されない）。例題 ABC211 D も $s$ からの距離だけで本数を求めており、本文の中で食い違う
- **根拠**：本文 82〜98 行の DP（図の例で $\mathrm{cnt}[t] = 6$ は $s$ からだけで出る。$e$ の枝は $t$ に寄与しない）。edge-classify.cpp も本数は ds だけで数え、brute.py の比較で一致
- **直し方**：「$s$-$t$ 最短路に乗る辺や頂点を問われたら、$\mathrm{dt}$ も求めて上の等式で絞る（本数だけなら $\mathrm{cnt}[t]$ でよい）」とする

### 3｜直すとよい｜fact（F2）｜#build の重み 0 の段落（67 行）

- **問題**：「重み 0 の辺 $u \to v$ は、両端の距離が等しければ $u \to v$ と $v \to u$ の両方がきつい」は、有向の辺 $u \to v$ には $v \to u$ がないので文として合わない。無向の重み 0 の辺なら、両端の距離は必ず等しい（$\lvert \mathrm{dist}[u] - \mathrm{dist}[v] \rvert \le 0$）ので「等しければ」の条件も要らない
- **根拠**：三角不等式を両向きに使うと $\mathrm{dist}[v] \le \mathrm{dist}[u]$ と $\mathrm{dist}[u] \le \mathrm{dist}[v]$
- **直し方**：「有向の重み 0 の辺 $u \to v$ は、両端の距離が等しいときにきつい。無向の重み 0 の辺 $\{u, v\}$ は、両端の距離が必ず等しくなるので両方の向きがきつく、それだけで長さ 2 の閉路になる」とする

### 4｜直すとよい｜fact（F2）｜#count-paths の mod の注意（100 行）

- **問題**：「mod を取った値の大小や等しさは、元の本数の大小や等しさと一致しない」は言い過ぎ。等しい本数は mod でも必ず等しい。一致しないことがあるのは「mod で等しい → 本数が等しい」の向き（と大小）
- **直し方**：「mod を取った値の大小は元の本数の大小と関係がなく、mod で等しくても本数が等しいとは限らない」とする

### 5｜直すとよい｜fact（F2）・clarity（U8）｜確認問題「未到達の頂点からの足し込み」の答え（106 行）

- **問題**：「たまたま負の値に回り込むと、意味のない等式が成り立つこともある」は、重みが非負なら起きにくい（回り込んだ負の値は、0 以上か `INF` の $\mathrm{dist}[v]$ と等しくならない）。実際に起きうる誤りは別で、重み 0 の辺では、あふれなくても `INF + 0 == INF` が成り立ち、到達できない頂点どうしの辺がきつい辺に見える（本数は 0 なので数え上げは無害だが、辺の分類や最短路木では誤る）。`LLONG_MAX / 4` にしても同じ
- **根拠**：`LLONG_MAX + w`（$w \ge 1$）は回り込めば負、`dist` は 0 以上か `INF`
- **直し方**：答えを「到達できない頂点 $u$ では `dist[u] + w` があふれて未定義動作になる。あふれない `INF` にしても、重み 0 の辺では `INF + 0 == INF` が成り立ち、到達できない頂点どうしの辺がきつい辺と判定される。$\mathrm{dist}$ が有限の頂点だけを調べる」とする
