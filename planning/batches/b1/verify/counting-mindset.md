## 指摘

### 1｜直すべき｜事実（F2）・分かりやすさ（U2）｜#pitfalls の 2 つめ（160 行）、#abc156_e の本文（214 行）と解法の詳細（219 行）

- **問題**：「移動して戻る往復で余りの移動を使い切れる」「ある人が別の部屋へ移って戻る 2 回で、余った移動を消費できる」とあるが、往復は 2 回ずつしか消費しないので、余りが奇数のときは使い切れない。実際には 3 部屋をめぐる 3 回（A→B、B→C、C→A）などを組み合わせて奇数も消費するので、部屋が 3 つ以上あることが要る。部屋が 2 つなら偶奇が変わらず、式は成り立たない。読者が「余りが奇数なら？」と問うと、本文では答えられない
- **根拠**：移動の列の全探索。$n = 2$・$k = 2$ で実際は 1 通り（$(1, 1)$ だけ）、式は 3。$n = 2$・$k = 3$ で実際は 2、式は 3。$n \ge 3$・$k \ge 2$ ではすべて一致した。執筆者も報告の未解決の点で「$k - z$ が奇数のときは別の部屋を経由させる遠回りで 1 回増やせる」と書いているが、本文にはない
- **直し方**：219 行を「$k \ge 2$ なら、余りが偶数なら移って戻る 2 回、奇数なら 3 部屋をめぐる 3 回（部屋が 3 つ以上あるとき）を組み合わせて、余った移動を消費できる」のようにする。160 行と 214 行の「往復で」も「往復や 3 部屋をめぐる移動で」にそろえる。問題の制約で部屋が 3 つ以上と決まっているなら、その旨を添える（制約は ap.py と台帳の evidence で確かめてから書く）

### 2｜直すべき｜事実（F2）｜#abc127_e の解法の詳細の 3 つめ（234 行）

- **問題**：「$M^2$ を mod なしで掛けると `long long` でもあふれることがある」は誤り。$NM \le 2 \times 10^5$ の範囲では、距離の総和そのもの $\sum_d d(N-d)M^2 + \sum_d d(M-d)N^2$ が最大でも約 $1.33 \times 10^{15}$ で、`long long` に収まる。あふれるのは、mod を取らない総和（または $M^2$ を含む積）に $\binom{NM-2}{K-2}$（$10^9$ 程度の値）を掛けるときである
- **根拠**：$N = 1 \sim 2 \times 10^5$・$M = \lfloor 2 \times 10^5 / N \rfloor$ で総和を正確に計算し、最大が $1333333333300000 \approx 1.33 \times 10^{15} < 2^{63}$（$N = 2 \times 10^5$・$M = 1$）。制約 $NM \le 2 \times 10^5$ は本文の「$O(NM)$」の前提として台帳の evidence（drken の記事）による
- **直し方**：「距離の総和は `long long` に収まるが、$\binom{NM-2}{K-2}$ を掛ける前に mod を取らないとあふれる」とする。または「`int` で $M^2$ を計算するとあふれる」と型を正しく言う

### 5｜直すとよい｜分かりやすさ（U3）｜#formula-or-dp（87 行）

- **問題**：「同じ色になる $j$ 組の位置の選び方は $\binom{N-1}{j}$ 通り」の $N - 1$ がどこから来るかが書かれていない。「組」が隣り合う 2 つのブロックの組のことで、それが $N - 1$ 個あることを読者が補う必要がある
- **根拠**：本文の直前の文は「隣が同じ色の組がちょうど $j$ 組」とだけ言う
- **直し方**：「隣り合う組は $N - 1$ 個あり、そのうち同じ色になる $j$ 組の選び方は $\binom{N-1}{j}$ 通りである」とする

### 6｜直すとよい｜事実（F5）｜#challenge の ABC180 F の方針（260 行）

- **問題**：「パスは $k = 1$、サイクルは $k = 2$（多重辺）の扱いが特別」とあるが、単純グラフでは $k = 1$ のサイクル（自己ループ）も作れない。$k = 2$ だけを挙げると、$k = 1$ のサイクルを数えてしまう読者が出る
- **根拠**：単純グラフでは長さ 1・2 の閉路はない。$k$ 頂点のサイクルの数は $k \ge 3$ で $(k-1)!/2$、$k \le 2$ では 0
- **直し方**：「パスは $k = 1$（1 通り）、サイクルは $k \le 2$（自己ループ・多重辺になるので 0 通り）が特別」とする

### 7｜直すとよい｜記法（F7）｜#verify-small の箇条の 2 つめ（153 行）

- **問題**：「$n = 1$・$m = 1$・$K = 0$ など」で、この節の変数は $n$・$m$・$k$・$j$ なのに $K$ だけ大文字で、何の $K$ かが節の中にない（断片で読むと分からない。U6）
- **根拠**：144 行の説明とコード片は $n$・$m$・$k$・$j$ を使う
- **直し方**：「$j = 0$（同じ色の組が 0 組）」か「$k = 1$」など、この節の変数で書く。$0^0$ が出るのはコードでは $m = 1$・$j = n - 1$ と $k = 1$・$n$ の組なので、そのどちらかを例に挙げるとよい

### 8｜直すとよい｜事実（F4）｜#pitfalls の最後（166 行）

- **問題**：「ACL の `pow(0)` は 1 を返す」は正しいが、言いたいのは「底が 0 でも」である。`pow(0)` だけでは $x^0 = 1$ の当たり前の話に読める

- **直し方**：「ACL の modint では `mint(0).pow(0)` も 1 を返す」とする
