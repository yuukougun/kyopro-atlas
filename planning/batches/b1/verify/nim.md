### 2｜直すとよい｜fact（F2）・clarity（U3）｜#arc168_b の解法の詳細（211 行）

- **問題**：「ニム和 0 の $D$ には異なる値が 3 つ以上あるので $M \ge 3$」は、$D$ の値がすべて 1 以上であることを使っている。0 個の山が奇数個あると $D = \{0\}$ でも XOR は 0 になり、主張が崩れる。本文には山が 1 個以上であることが書かれていない
- **根拠**：$\{0\}$ の XOR は 0。異なる正の値 2 つの XOR は 0 にならず、3 つで最大が 3 以上になるのは $\{1, 2, 3\}$ が最小
- **直し方**：「山の個数はどれも 1 以上なので、ニム和 0 の $D$ には異なる値が 3 つ以上あり $M \ge 3$ で…」と前提を書く（制約は問題文で確かめられないので、メインが確かめられない場合は「異なる正の値 2 つの XOR は 0 にならないので」と理由の形で書く）
