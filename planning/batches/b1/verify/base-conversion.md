## 指摘

### 1｜直すべき｜事実（F7）・分かりやすさ（U3）｜#base-binary-search、オーバーフローの段落の「整数 $v$ と $m - d \ge 0$ について」と、その下の式

- **問題**：(a) 本文の上限は大文字の $M$ なのに、ここだけ小文字の $m$ になっていて、定義のない記号になっている。(b) 同じ節の「単調性」で $d$ を「$X$ の最大の数字」と定義した直後に、式 $v \cdot n + d \le M$ の $d$ を「いま足す 1 桁の数字」の意味で使っている。読者は「最大の数字を足すのか」と迷う。コード片は最大の数字を `d`、各桁を `dig` と分けているので、本文とコードの記号もずれる（C3）
- **根拠**：本文の節の「したがって、使える基数は $X$ の最大の数字を $d$ として」と「番兵：ok は…$d$、ng は $\max(M, d) + 1$」が最大の数字の意味。base-n.cpp 24〜26 行は `dig`
- **直し方**：「整数 $v$ と、いま足す数字 $c$（$0 \le c \le M$）について $v \cdot n + c \le M \iff v \le \lfloor (M - c)/n \rfloor$」のように、各桁の文字を $d$ 以外（$c$ や $d_i$）にし、$m$ を $M$ に直す

### 2｜直すとよい｜分かりやすさ（U4）｜#base-binary-search、「番兵」の段落

- **問題**：「ok は『まだ 1 つも数えていない』位置の $d$」だけでは、[答えで二分探索](../basics/binary-search-answer.md)で「ok は条件を満たす側」と学んだ読者が、「$n = d$ で $f(d) \le M$ とは限らないのに ok に置いてよいのか」で止まる
- **根拠**：上の検査のとおり、mid は常に ok より大きいので $n = d$ は判定されず、答えは正しい。理由が本文にないだけ
- **直し方**：「$n = d$ は調べられることがない（mid は常に ok より大きい）ので、$f(d) \le M$ でなくてよい。すべての $n \ge d + 1$ で条件を満たさなければ ok は $d$ のまま残り、答えは 0 になる」と 1〜2 文足す

### 3｜直すとよい｜事実（F2）｜#negative-base、「C++ の `%` と `/` である。どちらも 0 方向への切り捨てなので」

- **問題**：`%` は切り捨ての演算ではない。正確には「`/` が 0 方向への切り捨てで、`%` はそれに合わせた余り（割られる数と同じ符号）」である
- **根拠**：C++ の規格（C++11 以降）は `a / b` を 0 方向へ切り捨て、`(a / b) * b + a % b == a` を満たすよう `%` を定める（cpprefjp・cppreference の算術演算子の項）
- **直し方**：「C++ の `/` は 0 方向へ切り捨て、`%` はそれに合わせて割られる数と同じ符号になる。そのため $N < 0$ のとき `N % 2` は $-1$ になりうる」とする

### 4｜直すとよい｜図（G3・G5）｜ladder.svg

- **問題**：(a) 位の説明が「3^0」「3^1」「3^2」とキャレットの書き方で、本文の $3^0$ と見た目が違う。右下の「212₃」は下付き文字を使っているので、図の中でも書き方がそろっていない。(b) 位の注記と最下段の説明が font-size 13 で、幅 390px の画面（本文の幅は約 358px）では 520 から縮んで実質 9px ほどになり読みにくい
- **根拠**：幅 390 の画像で注記の文字が小さいことを目で確かめた
- **直し方**：(a) `3<tspan baseline-shift="super" font-size="10">0</tspan>` か「3⁰・3¹・3²」にする。(b) 注記を 14〜15 に上げるか、右の「下から読む」の矢印を詰めて横幅を 460 程度にする

### 5｜直すとよい｜分かりやすさ（U6）｜#base-binary-search の冒頭「$f(n) \le M$ となる $n$ を数える問題では」

- **問題**：練習の ABC192 D と要点は「値が何種類か」を問う形である。2 桁以上では狭義単調増加なので「$n$ の個数 = 値の種類数」になるが、そのことが節の中で一言も結び付けられていない。1 桁の場合分けで「値が何種類か」が突然出てくる
- **根拠**：要点の signs「$n$ を数える」と、練習の要約「何種類あるか」
- **直し方**：「単調性」の段落の最後に「狭義単調増加なので、異なる $n$ は異なる値を与え、$n$ の個数がそのまま値の種類数になる」と足す
