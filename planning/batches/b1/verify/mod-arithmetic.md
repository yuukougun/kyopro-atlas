## 指摘

1. 重さ：直すべき／観点：fact（F2）／場所：#division 第 1 段落「$12 / 4 = 3$ でも、余りは $0 / 1 = 0$ になって本当の余り $0$ と一致するのは偶然である」
   - 問題：偶然ではない。割る数 $b$ が $m$ と互いに素なら、余りどうしの整数の割り算が割り切れたとき、その商は必ず本当の商と合同になる（$b q' \equiv b q$ から逆元を掛けて $q' \equiv q$）。$4 \bmod 3 = 1$ は 3 と互いに素なので、この例は「一致が保証される側」の例である。後の「逆元を掛ける」の説明とも食い違って見える
   - 根拠：$m < 30$、$b < 60$、$q < 60$ を全探索し、$\gcd(b, m) = 1$ で余りの割り算が割り切れるのに本当の商と合わない例は 0 件
   - 直し方：一致しない例に差し替える。たとえば「$m = 4$ で $12 / 2 = 6$ を考えると、本当の余りは $6 \bmod 4 = 2$ だが、余りどうしでは $0 / 2 = 0$ になる」。割り切れない例（$4/2$ で $1/2$）と、割り切れるのに値が違う例の 2 つを見せれば「割り切れるかどうかの情報が失われる」の一文も支えられる

2. 重さ：直すべき／観点：fact（F2）／場所：#next-steps「逆元と mod での割り算」の項「素数 $p$ なら $b^{p-2}$ が $b$ の逆元になる」
   - 問題：条件「$b$ が $p$ の倍数でない」が落ちている（チェックリスト F2 のフェルマーの典型の書き落とし）。同じ節の次の項（exponent-mod）では条件を書いているので不揃いでもある
   - 根拠：$b = p$ なら $b^{p-2} \equiv 0$ で、$b \cdot 0 \not\equiv 1$
   - 直し方：「素数 $p$ なら、$p$ の倍数でない $b$ について $b^{p-2}$ が逆元になる」

3. 重さ：直すとよい／観点：fact（F1・F10）／場所：front matter `complexity`「（法が 32bit に収まるとき）」と要点の計算量「法 $m$ が $2^{31}$ 未満なら」
   - 問題：2 か所の条件が食い違う。「32bit に収まる」を符号なし 32bit と読むと $m < 2^{32}$ で、$(m-1)^2$ は `long long`（$2^{63} - 1$）に収まらない
   - 根拠：$(2^{32} - 1)^2 \approx 1.8 \times 10^{19} > 2^{63}$、$(2^{31} - 1)^2 < 2^{63}$
   - 直し方：`complexity` を「足し算・引き算・掛け算 1 回あたり O(1)（法が 2^31 未満のとき）」にそろえる（complexity は執筆者が変えてよい項目）

4. 重さ：直すとよい／観点：fact（F2）・clarity（U3）／場所：#no-compare 3 つ目の項「途中の値の正負や偶奇で場合分けする」
   - 問題：「余りの偶奇は本当の値の偶奇と関係がない」は無条件に読めるが、$m$ が偶数なら余りの偶奇は本当の値の偶奇と一致する（括弧の「$m$ が奇数なら」が条件だと伝わりにくい）。また見出しの「正負」について本文で何も説明していない
   - 根拠：$m$ 偶数なら $x = qm + r$ で $x \equiv r \pmod 2$
   - 直し方：「法が奇数（998244353 や $10^9+7$）だと、余りの偶奇は本当の値の偶奇と関係がない（$8 \bmod 7 = 1$）」とし、正負についても「余りは常に 0 以上なので、本当の値が負かどうかは分からない」を 1 文足す（足さないなら見出しから「正負」を外す）

5. 重さ：直すとよい／観点：clarity（U7）／場所：#pitfalls「最後にだけ余りを取る」
   - 問題：例が「$N!$ を $10^9 + 7$ で割った余り。掛けるたびに余りを取る」で、練習の ABC055 B の問いと解き方そのものになっている。練習の方針を折りたたみに入れた意味が薄れる
   - 直し方：例を別のもの（$2^N$ や入力の数の積など）に替えるか、ABC055 B を練習から外して本文の例として扱う

6. 重さ：直すとよい／観点：figure（G7）／場所：clock.svg と catalog の visual
