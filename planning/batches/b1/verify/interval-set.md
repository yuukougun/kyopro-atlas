### 2｜直すべき｜fact（F5）｜#challenge の「力試しの方針」ABC255 Ex（226 行）

- **問題**：「答えが大きくなるので型に注意する」とあるが、この問題は答えを 998244353 で割った余りで出力する。木の番号の上限（$N$）も日付も `long long` の範囲まで大きく、番号の和 $\frac{(a + b - 1)(b - a)}{2}$ は `long long` に収まらない。「型に注意」だけでは、余りを取らずに `long long` や `__int128` で正確な値を求めようとする読み方になり、方針として誤る
- **根拠**：evidence の kmjp の記事のコード（`const ll mo=998244353;`、出力の前に `%mo`、`ll N,Q;`・`ll D[],L[],R[]`、和を `__int128` で `(L+R-1)*(R-L)/2%mo`）
- **直し方**：「答えは 998244353 で割った余りを求める。番号の和は掛け算の途中で `long long` を超えるので、`__int128` で計算してから余りを取るか、2 の逆元を使って mod の下で計算する」とする

### 3｜直すべき｜fact（F1・F2）｜#valued-intervals の最後のまとめ（271 行）

- **問題**：「どの場合も、差分を流す回数は区間ができる回数と消える回数の合計に比例するので、評価に $\log N$ が 1 つ掛かるだけで済む」は、すぐ上の節で扱う割り算の場合に成り立たない。割り算では区間を消さずに値だけが変わり、そのたびに BIT へ差分を流す。たとえば最初に値の違う $N$ 個の区間があり、全体を 2 で割る操作を $\log_2 \max A$ 回すると、区間ができる・消える回数は $O(N + \log \max A)$ なのに、差分を流す回数は約 $N \log_2 \max A$ になる。差分の回数は「区間の値が変わる回数」で、代入だけならそれが消える回数と同じになる、というのが正しい関係である
- **根拠**：上の反例の数え方。263 行の本文自身も割る回数の合計を $O((N + Q) \log \max A)$ と数えている。ABC256 Ex の計算量は $O((N + Q) \log \max A \log N)$ 程度になる
- **直し方**：「差分を流す回数は、区間の値が変わる回数（代入だけなら消える回数、割り算なら上で数えた割る回数）に比例する。その回数に $\log N$ が 1 つ掛かる」とする

### 4｜直すとよい｜fact（F1）・clarity（U1）｜要点の計算量（43 行）

- **問題**：要点の計算量は「ならし $O(\log N)$（$N$ は区間の数）」で、条件として「各区間が消えるのは一度だけ」しか書いていない。区間をたどるだけで消さない操作（区間和の質問・区間加算）が混ざると崩れることは、front matter の complexity の条件（区間が生まれる回数…）と本文の #amortized・warning にしかなく、冒頭だけで引く読者は ODT として区間和の質問まで同じ構造で処理してよいと読みうる
- **根拠**：checklists/fact.md F1（3 か所の一致とならしの条件）、clarity.md U1（計算量に条件がない）
- **直し方**：要点の計算量の末尾に「区間をたどるだけで消さない操作（区間和の質問・区間加算）が混ざると、この評価は成り立たない」を足す

### 5｜直すとよい｜fact（F2）｜#pitfalls の「空の区間」（161 行）

- **問題**：「$l = r$ の代入で…区間 $[l, l)$ を入れると、長さ 0 の区間ができ、キー $l$ にあった区間を上書きしてしまう」。左端をキーにした map の形では長さ 0 の区間はできず、起きるのは「キー $l$ から始まる区間 $[l, b)$ の値が $v$ に変わる」こと（split(l) で $l$ がキーになっているため）。「長さ 0 の区間ができ」は set に $(l, r, v)$ を入れる書き方の話で、map の形の説明としては不正確
- **根拠**：paint.cpp の `assign` で `if (l >= r) return;` を外し、$N = 5$ に `1 2 2 9` を入れると、$[2, 5)$ が値 9 になる（split(2) の後 `mp[2] = 9`）
- **直し方**：「$l = r$ のとき、split の後の `mp[l] = v` は、キー $l$ から始まる区間 $[l, b)$ の値を $v$ に書き換えてしまう（何も塗らないはずが $b - l$ マス塗られる）」とする
