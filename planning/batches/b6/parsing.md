## 練習の候補（practice）

### abc350_f　F. Transpose（diff 1601・青）

- 要約：英大文字・英小文字と対応の取れた括弧からなる文字列で、括弧の中を逆順にして大文字と小文字を入れ替え、括弧を消す操作を内側からくり返した後の文字列を求める。
- 方針の要点：括弧の対応を先にスタックで求め、区間と向きを引数にとる再帰で「開き括弧に当たったら中身を逆向きで読んで対応する括弧の先へ飛ぶ」と走査すれば、各文字を 1 回ずつ読むだけの $O(\lvert S \rvert)$ で済む（大小の入れ替えは囲む括弧の深さの偶奇で決まる）。
- このページとの対応：signs の「入れ子の構造を持つ文字列」に当たり、#why-it-works（呼び出しの木が括弧の入れ子に一致する）と #deep-nesting（長さ 5×10^5 なので入れ子が深いと再帰が深くなる）の両方を使う。四則演算の式ではないので、本文で使うなら「式でない入れ子の文字列も同じ形で読む」例として紹介することになる
- 裏付け：
  - https://torus711.hatenablog.com/entry/2024/04/21/194303 （制約 |S| ≤ 5×10^5、素朴な模擬は Θ(|S|^2)、対応表と向きを切り替える再帰で Θ(|S|)）
  - https://qiita.com/_mattu34_/items/9eb21e83d9f86aa10d79 （dfs(l, r, d) で向き d を XOR で反転させる再帰）

### joi2020_yo2_e　E. じゃんけん式 (Rock-Scissors-Paper Expression)（diff なし）

- 要約：R・S・P と ?・括弧・+・-・* からなる式（* が + と - より先に結びつく）で、? を R・S・P に置き換える方法のうち、式の結果が指定の手になるものの数を 10^9+7 で割った余りで求める。
- 方針の要点：式・項・因子の再帰下降構文解析で、各関数が 1 つの値の代わりに「結果が R・S・P になる置き換え方の数」の三つ組を返し、演算子ごとの表で三つ組を掛け合わせて合成する。
- このページとの対応：#bnf の 3 段の文法そのもので、返す値を数え上げの組に変えるだけで解ける。#grammar-dp（文法に沿った DP）の易しい形でもある
- 帯について：difficulty がないので帯は判断できない。JOI 二次予選の E で、満点は青のページの練習に合う重さと見るが、根拠は解説の内容だけ
- 裏付け：
  - https://blog.hamayanhamayan.com/entry/2019/12/22/002709 （はまやん氏。再帰下降で解析し、各部分式が R・S・P ごとの数の三つ組を返して演算子ごとに合成する。mod 10^9+7 はコードから）
  - 2 つ目の解説は見つけられなかった（Web 検索の上限に達したため）。同じ筆者のまとめ https://blog.hamayanhamayan.com/entry/2019/11/09/180622 で「構文解析」に分類されていることは確かめた
- 未確認：N の上限（記事のバッファから 10^6 程度と読めるだけで、明記はない）。本文に書くなら別の資料で確かめる

### arc122_a　A. Many Formulae（diff 783・基礎）

- 要約：長さ N の非負整数列の間に + か - を入れ、- が 2 つ続かない式すべてについて、値の合計を 10^9+7 で割った余りで求める（N ≤ 10^5）。
- 方針の要点：左から数を 1 つずつ読み、「最後の演算子が + か - か」ごとに式の数と値の和を持てば、新しい数 d を足すときの更新は個数と d の積を足し引きするだけの O(1) になり、全体で O(N) になる。
- このページとの対応：#substring-sum（式の部分文字列の総和）の「すべての式について和のまま更新する」考え方の易しい版で、例題 arc061_a（全通りの式の和を bit 全探索で）の N が大きい版でもある。力試し abc338_g の前の段として置ける
- 帯について：difficulty は基礎の帯で青より下。練習の abc380_b（27）も基礎なので易しい側の練習として置けるが、外すかはメインの判断（帯の上に離れたものではないので力試しには向かない）
- 裏付け：
  - https://zenn.dev/hal_mat/articles/0c3857b22b6ff1 （+ で終わる式・- で終わる式の個数と値の和の 4 つを持つ DP）
  - https://ikatakos.com/pot/programming_algorithm/contest_history/atcoder/2021/0612_arc122 （制約 N ≤ 10^5・mod 10^9+7、各項が正と負で数えられる回数に分ける別の方針）
