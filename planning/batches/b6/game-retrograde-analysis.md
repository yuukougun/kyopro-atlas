### abc245_f（practice）

- 問題ID：abc245_f
- 題名：F. Endless Walk
- difficulty：1451（水）
- 役割：practice
- 要約：有向グラフで、そこから辺をたどって無限に移動し続けられる頂点の数を求める問題である。
- 方針の要点：出次数 0 の頂点をキューに入れ、逆辺をたどって行き先の頂点の出次数のカウンタを減らし、0 になった頂点を次々と取り除き、最後まで残った頂点を数える（このページの「カウンタ」と「決まらない局面」の部分だけを使う）。
- 裏付け：
    - https://kyo-pro.hatenablog.com/entry/ABC245F （「後退解析」として、出次数のカウンタ・逆辺・キューで取り除く手順を説明している）
    - 台帳 data/problems.yaml に確認済みで登録ずみ（topological-sort の practice）
- 注意：2 人のゲームではない（勝ち・負けの非対称な規則は出てこない）。帯（黄）より下で、1 問を topological-sort と 2 ページで練習にすることになる。採るかどうかはメインの判断に任せる（b3 の報告と同じ提案）

### arc038_d（challenge）

- 問題ID：arc038_d
- 題名：D. 有向グラフと数
- difficulty：3009（参考値。発展）
- 役割：challenge（帯から大きく離れる。既存の力試し abc261_h に足す形）
- 要約：各頂点に値のある有向グラフで、頂点 1 の駒を 2 人が交互に辺に沿って動かすか終了を宣言し、終了時（または非常に多くの手で打ち切られた時）の頂点の値を先手は大きく後手は小さくしたいとき、最適に動いたときの値を求める問題である。
- 方針の要点：答えを二分探索し、「値が D 以上で終われるか」を（頂点, 手番）の 2N 状態のゲームとして、終了宣言で勝敗が決まる状態を起点に逆辺と出次数のカウンタで勝ち・負けを確定させ、確定しない状態は先手の勝ちとは扱わずに判定する。
- 裏付け：
    - https://drken1215.hatenablog.com/entry/2019/01/28/103000 （drken の「後退解析」カテゴリの記事。二分探索・2N 状態・逆辺とカウンタ・未確定の扱い）
    - https://kmjp.hatenablog.jp/entry/2015/05/03/1000 （同じ方針）
- 注意：打ち切りの手数は記事の表記からは確かめきれなかった（10^9 と読めるが未確認）。要約では数を書かない

## 探した範囲と結果

- (1) これまでの候補：b3 の candidates.md と b3/game-retrograde-analysis.md に abc245_f だけがあった。b1・b5 の candidates.md にはこのページの候補はない
- (2) 台帳：pages に game-retrograde-analysis を持つのは abc209_e（example）と abc261_h（challenge）だけで、どちらも本文にある
- (3) 第三者の解説：kanpurin の典型問題メモの「後退解析」の項は abc209_e と abc261_h の 2 問だけ。kyo-pro の「解法パターンの整理」のゲームの項は abc209_e だけ。AtCoder Tags の Graph/Game（57 問）で閉路のある局面のゲームは abc209_e だけだった。drken の「後退解析」カテゴリ（15 記事）から AtCoder のゲームは arc038_d を拾った
- 外したもの：
    - MUJIN 2018 D（うほょじご）：drken の「後退解析」カテゴリにあるが、2 人のゲームではなく決定的な操作が止まらない状態を数える問題（abc245_f と同じ型）。ap.py の contest でコンテストを引けず、difficulty を確かめていないので候補にしない
    - abc278_f（Shiritori、1452）：題名は近いが、単語の使用を 1 回に限る bit DP で、閉路がない
    - arc038_b（マス目と駒、1378）：右・下への移動だけで局面が DAG になり、ふつうの勝敗の DP で足りる
    - abc298_e・agc014_d・arc097_f など「後退解析」の語で出てくる問題は、ゲームの後退解析ではない（確率の DP・木の葉からの貪欲など）
- 結論：閉路のある局面で勝ち・負け・引き分けを求める 2 人のゲームで、黄の帯に近い練習向けの問題は見つからなかった。練習に足せるのは abc245_f（ゲームではない部分練習）の 1 問だけで、目標の 2〜4 問には届かない。無理には足さない
