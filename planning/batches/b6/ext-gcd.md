## 候補

### abc340_f（台帳になし）

- 問題ID：abc340_f
- 題名：F. S = 1
- difficulty：1516（水）
- 役割：practice
- 要約：整数の点 (X, Y) が与えられ、原点と (X, Y) と (A, B) を頂点とする三角形の面積がちょうど 1 になる整数の点 (A, B) を 1 つ求める（なければ −1 を出す）。
- 方針の要点：面積は |AY − BX| / 2 なので、Y·A − X·B = ±2 という一次不定方程式になり、g = gcd(|X|, |Y|) が 2 を割り切るとき（g = 1 なら拡張ユークリッドの解を 2 倍、g = 2 ならそのまま）だけ解がある。
- 裏付け：
    - https://programming-hiroba.com/abc340-f/ （面積を 2×2 の行列式で表し、`extgcd(y, -x)` の結果で d = 1 なら 2 倍、d = 2 ならそのまま、それ以外は −1 とする方針を確かめた。付録 B のドメイン）
- 確かめきれなかった点：この記事は問題文を載せておらず、X・Y と出力の範囲の制約は確かめていない。2 件目の第三者の解説は見つからなかった（kmjp は ABC340 の記事が G だけ、drken には記事がない。Web 検索が使えなかった）。台帳に入れる前に、メインで制約をもう 1 件の解説で確かめたい
- 本文に足すときのメモ：本文の「応用の型」は型（面積 1 の格子点）だけを書いているので、台帳に入れば練習の囲みと方針の折りたたみに足せる（b1 の報告の提案と同じ）

### acl1_b（台帳にあり。crt の例題・divisor-count-bound の練習）

- 問題ID：acl1_b
- 題名：B. Sum is Multiple
- difficulty：1785（青）
- 役割：challenge（水の帯の上の青なので力試し）
- 要約：1 + 2 + … + k が N の倍数になる最小の正の整数 k を求める（N ≤ 10^15）。
- 方針の要点：k(k + 1) が 2N の倍数という条件に直し、2N を互いに素な A·B（A | k、B | k + 1）に分ける方法ごとに、k = Aq とおいた一次合同式 Aq ≡ −1 (mod B)（法 B は素数とは限らない）を拡張ユークリッドで解いて最小を取る。
- 裏付け：
    - https://drken1215.hatenablog.com/entry/2020/09/23/080300 （N ≤ 10^15、2N = AB の分け方が最大 2^13 通り、関係式 A(−q) + Br = 1 を拡張ユークリッドで解く方法と CRT で解く方法の両方が載っていることを確かめた。記事のカテゴリも「拡張 Euclid の互除法」）
- 注意：台帳では crt の example なので、§10 の「例題は 1 問につき 1 ページ」に従い、ext-gcd では力試しとして crt の例題へリンクする形がよい。drken の記事の拡張ユークリッドのコードは `(A * -q) % N` で 64 ビットを超えうる（q を先に B で割った余りにしてから掛ける）。本文の「係数のあふれ」の節と対応させられる

### abc315_g（台帳になし）

- 問題ID：abc315_g
- 題名：G. Ai + Bj + Ck = X (1 <= i, j, k <= N)
- difficulty：2315（黄）
- 役割：challenge
- 要約：正の整数 N・A・B・C・X が与えられ、1 ≤ i, j, k ≤ N を満たし Ai + Bj + Ck = X となる組 (i, j, k) の個数を求める。
- 方針の要点：i を全探索すると Bj + Ck = X − Ai という一次不定方程式になり、gcd(B, C) で割り切れない i は飛ばし、割り切れれば 1 つの解から一般解 j = j0 + t·C/g の形で 1 ≤ j, k ≤ N を満たす t の範囲の長さを数える。
- 裏付け：
    - https://kmjp.hatenablog.jp/entry/2023/08/21/0900 （X から A + B + C を引いて添字を 0 始まりにし、i ごとに g = gcd(B, C) で割り切れるかを見て、ext_gcd を使う crt 関数で j の 1 つの解を作り、j の最小と最大から個数を数える方針を確かめた。付録 B のドメイン）
- 確かめきれなかった点：記事に N・A・B・C・X の数値の制約がなく、確かめていない（i の全探索なので N は 10^6 程度までと思われるが未確認。オーバーフローの見積もりにも要る）。2 件目の解説は programming-hiroba の abc315-g が 404 で、ほかは Web 検索が使えず見つからなかった
- 本文に足すときのメモ：「最小の非負解への調整」と「一般解」の節の両方を使い、解の個数を数える練習になる。黄の帯の上の方なので力試しの最後に置く
