# 図の検証のチェックリスト

コードと図の検証役（書いた本人とは別のエージェント）が使う。渡されるもの：ページ、`docs/img/<page-id>/` の図、動く図の JS（`overrides/assets/js/viz/<名前>.js`）と試験（`tests/viz/<名前>.test.mjs`）、catalog のそのページの `visual`、このチェックリスト、執筆の手引き（`planning/style-guide.md` §8）。設計書 §8.5・§8.6、design-review D8・D19。

- 指摘は 1 件 1 行で「図（ファイル名か data-viz の名前）とステップ｜項目（G1 など）｜内容｜確かめた結果｜直し方の案｜重さ（必須／推奨）」の形で一覧にする
- 確かめた環境（ブラウザ、画面の幅、ライト・ダーク）を記録に残す

## G1 状態の列の正しさ（動く図）

- **確かめ方**：`node --test "tests/viz/*.test.mjs"` を実行する。試験が「各状態で保つ性質」と「最後の状態が答え（全探索などの素朴な方法と比べる）」を確かめているかを読む。本文の例の config で最初から最後まで送り、各ステップの caption と描かれた値を本文の説明・手計算と照らす。境界の config（1 要素・同じ値・答えが端）と、不正な config（例外になること）も試す
- **よくある失敗**：1 ステップに 2 つの変化が混ざる。caption と描かれた状態がずれる。最後の状態が答えと違う。試験が状態の数だけを見ている。不正な config で例外にならず、変な図を描く

## G2 ブラウザで動くか

- **確かめ方**：ヘッドレスのブラウザでの検査（道具は tools/README.md）で JS のエラーがなく、図が取り付くこと。`mkdocs serve` で開き、別のページへ移って戻っても図が 1 つだけ正しく出るか（instant navigation）。最初・前・次・最後・自動再生・速度・キーボード（← → Home End Space）・スワイプを試す
- **よくある失敗**：`data-viz` の名前と登録名が違う。`data-config` の JSON の引用符の誤り（属性は単引用符、中身は二重引用符）。戻ったときに図が 2 つ出る・消える

## G3 スマホで読めるか

- **確かめ方**：幅 390px 程度で表示し（ブラウザの開発者ツール）、横にはみ出さないか、文字が読める大きさか、ボタンが指で押せる大きさ（44×44px 程度）かを見る。SVG に `viewBox` があり、縮んでも読めるか
- **よくある失敗**：SVG に固定の `width`・`height` だけを書いて縮まない。横長の図で文字がつぶれる。図の中の表の列が多すぎる

## G4 ダークモードで読めるか

- **確かめ方**：パレットをライトとダークに切り替えて両方で見る。静的な SVG は背景が白で塗られているか。動く図は kp.css の `.kp-v-*` の class（Material の CSS 変数）で色を付けているか。Mermaid の図が読めるか
- **よくある失敗**：背景が透明の SVG に黒い文字（ダークでは見えない）。動く図で `#000` などの色を直接書く。赤と緑だけで区別する（色覚の違いでも読めるよう、線の種類やラベルを併用する）

## G5 静的な図の内容

- **確かめ方**：図の値・ラベル・添字を本文と照らす。図が本文の主張（仕組み・保つ性質）を示しているか。代替テキストと前後の文章だけで要点が分かるか
- **よくある失敗**：図と本文で添字がずれる（0-indexed と 1-indexed）。図の例と本文の例が別。代替テキストが「図」だけ。飾りの図で主張を示していない

## G6 置き場所と形式

- **確かめ方**：SVG が `docs/img/<page-id>/` にあり、相対パス（`../img/<page-id>/<name>.svg`）で参照され、`mkdocs build --strict` が通るか。文字がテキストのまま（`font-family="sans-serif"`）か。欠けると困る図を Mermaid（CDN から読む）にしていないか。動く図の埋め込みが `<div class="kp-viz" data-viz="…" data-config='…'></div>` の形か
- **よくある失敗**：ほかのページのフォルダに置く。絶対パスや外部の URL の画像。文字を図形に変換していて検索できない。動く図の JS が DOM を使う処理を `states` に混ぜ、Node の試験で動かない

## G7 catalog の visual と、図の前後の文章

- **確かめ方**：catalog の `visual` が priority 1 の図がページにあり、`text`（何を見せるか）を満たすか。図の前後に要点の文章があり、JS が動かない環境（claude.ai が Markdown を読む場合）でも意味が通るか
- **よくある失敗**：priority 1 の動く図を静的な図で済ませる。visual の text と違うものを見せる。図の後に説明がなく、図を見ないと分からない
